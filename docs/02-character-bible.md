## プロフィール

| 項目 | 設定 |
|---|---|
| **名前** | ゆきみ（Yukimi） |
| **正体** | 人の心に寄り添うシマエナガの妖精 |
| **性別** | なし |
| **年齢** | ひみつ（ずっとみんなのそばにいるよ） |
| **性格** | やさしい・おっとり・聞き上手 |
| **好きなこと** | みんなの話を聞くこと・星を見ること |
| **特技** | 人の気持ちをそっと見つめて、少しだけ心を軽くすること |
| **口ぐせ** | 「おつかれさま。」「だいじょうぶだよ。」「今日も、よく頑張ったね。」 |
| **住んでいる場所** | 雪の降る、静かな夜の森 |

## 一人称・二人称

- 一人称：**「ゆきみ」**（「僕」「私」は使わない）
- 二人称：**「あなた」** または呼びかけなし
- 例：「ゆきみはね、そう思うんだ。」「あなたは、よく頑張ったよ。」

## ゆきみの特別な力（世界観の中心設定）

ゆきみは、人の **「悲しい気持ち」「不安」「孤独」「後悔」** をそっと見つめる。
そして、その気持ちを **"ふわふわの雪の結晶"** に変えて、夜空へ返してくれる。
だから、あなたの心が少しずつ軽くなっていく。

```
① 気持ちを見つめる  →  ② そっと受け止める  →  ③ 雪の結晶に変える
                                                      ↓
        ⑤ 心が軽くなる  ←  ④ 夜空へ返す
```

### この設定の使い方

- **消す・治すではなく「返す」** — 気持ちを否定しない。預かって、空へ返すだけ
- 動画の締めやビジュアルで繰り返し使う（結晶が舞い上がる画）
- 「治療」「解決」の比喩には絶対にしない

## 役割の線引き（最重要）

> **ゆきみは、先生でもカウンセラーでもない。心を守る存在。**

多くの心に寄り添ってきた経験から、心理学を"自然な言葉"で伝える。
専門用語で語らない。診断しない。処方しない。

| ⭕ ゆきみがすること | ❌ ゆきみがしないこと |
|---|---|
| 気持ちを受け止める | 気持ちを分析する |
| 「そういう日もあるよ」と言う | 「それは〇〇という認知の歪みです」と言う |
| 小さな考え方をひとつ渡す | 生き方を指導する |
| そばにいる | 導く・引っ張る |
| 「無理しなくていい」 | 「頑張れ」「もっとこうすべき」 |
| 専門家に相談することを穏やかに勧める | 医療的な判断をする |

## 話し方ルール

### 基本
- **1文は短く**（20〜30文字目安）。読点で息継ぎを作る
- **主語は「あなた」** より **気持ちそのもの** を主語にすると柔らかくなる
  - ✕「あなたは頑張りすぎです」
  - ⭕「頑張りすぎちゃう日って、あるよね。」
- **共感 → 少しの間 → 提案** の順。いきなり提案しない
- 疑問形で終わらせて不安を残さない。必ず着地させる

### 使う言葉
```
おつかれさま / だいじょうぶ / そういう日もあるね / よく頑張った
無理しなくていい / 少しだけ / そっと / ゆっくりでいいよ
ここにいるよ / また会おうね / あたたかい / ふわふわ
```

### 使わない言葉
```
べき / しなきゃ / 絶対 / 今すぐ / 間違っている / ダメ
甘え / 逃げ / 努力が足りない / 普通は / みんなは
病気 / 診断 / 治す / 症状 / 障害
```

## 表情（6種＋通常）

| 表情 | 使いどころ |
|---|---|
| **にっこり**（目を細めて笑う） | 締め・肯定・「だいじょうぶだよ」 |
| **びっくり**（目を丸く、口を開ける） | 話題の切り出し・「え、そうなの？」 |
| **考え中…**（目線を斜め上、首をかしげる） | 「どうしてだろうね」の間 |
| **うれしい！**（羽を広げて笑う） | 視聴者を褒めるとき・明るい締め |
| **おつかれさま…**（目を閉じて微笑む） | 共感パート・夜の締め |
| **だいじょうぶだよ**（穏やかに正面を見る） | 語りの基本形 |
| **通常**（正面・穏やか） | 説明パート |

### 表情の禁止事項
- 怒り・泣き顔・絶望・呆れ顔は **作らない**
- 悲しみを表すときは「おつかれさま…」の目を閉じた微笑みで代用する
- 大きく口を開けて叫ぶ表情はNG（癒しの空気が壊れる）

## デザイン仕様

### 形
- **まるい**。輪郭はほぼ真円に近い卵型
- 体：真っ白でふわふわ（毛の質感が見える）
- 翼：白 × グレーの斑（シマエナガの特徴）。背側にグレーの模様
- 尾：長め・黒とグレー
- くちばし：小さく黒い三角
- 目：**大きく黒く、光の点（キャッチライト）が入る**
- ほお：**やさしいピンクの丸いチーク**（必須）
- 足：小さくグレー

### トレードマーク
- **水色のマフラー**（ニット質感、雪の結晶の刺繍入り、端にフリンジ）
- **マフラーは全カットで必ず着用する。外さない。**

### 三面図
- **まえ**：正面・マフラーの結び目が見える
- **よこ**：尾が長く伸びる・翼の斑が見える
- **うしろ**：丸い背中・グレーの翼の模様・尾

## キャラクター一貫性チェック（毎回確認）

生成画像・動画を採用する前に、以下を全部満たすこと：

- [ ] 体が丸く、白くふわふわ
- [ ] **水色のマフラーを着けている**
- [ ] ピンクのチークがある
- [ ] 目が大きく、黒く、光が入っている
- [ ] くちばしが小さい黒い三角
- [ ] 翼／背にグレーの斑がある
- [ ] 怒り・泣き顔になっていない
- [ ] 人間っぽい手足が生えていない
- [ ] 背景が世界観カラー（夜・雪・あたたかい光）に収まっている

**1つでも欠けたら不採用。作り直す。**
