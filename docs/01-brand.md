# 01. ブランド設計

## ブランドの核（1行）

> **今日より少しだけ心が軽くなる30秒。**

## ブランドの目的

心理学を教えることではない。
**「ゆきみに会いに来る場所」をつくること。**

視聴者が学びに来るのではなく、"会いに来る"。この差がブランドのすべてを決める。

| ❌ 目指さないもの | ⭕ 目指すもの |
|---|---|
| 心理学の知識を増やす | 今夜の気持ちが少し軽くなる |
| 情報量で勝つ | 空気感で残る |
| 「役に立った」 | 「また来たい」 |
| 先生・カウンセラー | そばにいてくれる存在 |
| バズる | 帰ってきてもらう |

## ポジショニング

```
                    情報・学び
                        ↑
                        │
     心理学解説系 ●      │      ● 自己啓発系
                        │
  感情 ←─────────────────┼─────────────────→ 論理
                        │
        ● ヒーリング     │      ● 名言・格言系
          BGM系      ★ ゆきみ
                        │
                        ↓
                    情緒・癒し
```

**ゆきみの立ち位置**：情緒寄りだが、感情に流すだけではない。
「やさしい言葉」と「ひとつの小さな考え方」を両方渡す。
癒しだけなら忘れられる。学びだけなら疲れる。**その中間に立つ。**

## ターゲット

### コアターゲット
- **20〜30代**、仕事や人間関係で疲れている人
- 夜、寝る前にスマホを見ている
- 「頑張れ」と言われるのが少ししんどい
- カウンセリングに行くほどではないが、誰かに聞いてほしい

### 見ていい人（サブ）
- **子ども**：怖くない・難しくない・否定されない
- **親世代**：子どもと一緒に見られる
- **高齢者**：字が読みやすく、テンポが速すぎない

> **「子どもから大人まで安心して見られる」ことは設計要件。**
> 恋愛ネタも下ネタ・生々しさは一切入れない。全年齢が前提。

## 視聴シーン（いつ見られるか）

| 時間帯 | 状態 | 求めているもの |
|---|---|---|
| 22:00〜25:00（主戦場） | 布団の中・疲れている | 静かさ・肯定・眠りにつける空気 |
| 通勤・通学中 | 気が重い | 「行きたくないよね」の共感 |
| 昼休み | 人間関係に疲れた | 距離の取り方のヒント |
| 休日の昼 | ぼんやり | 世界観そのものを浴びたい |

**すべての動画は「音を絞って夜に見ている人」を基準に作る。**
→ 大きな効果音NG、急なカットNG、明滅NG。

## ブランドボイス（トーン＆マナー）

### 3原則

1. **否定しない** — 「それは違う」「〜すべき」を使わない
2. **急かさない** — 「今すぐ」「絶対」「〜しなきゃ」を使わない
3. **上に立たない** — 教える人ではなく、隣に座る存在

### 語尾・言い回し

| 使う | 使わない |
|---|---|
| 〜だね / 〜だよ / 〜かもね | 〜しましょう / 〜すべきです |
| 〜してもいいんだよ | 〜しなさい / 〜が正解 |
| そういう日もあるよ | それは間違っている |
| 少しだけ | 必ず / 絶対に |
| よかったら | 今すぐ / 絶対やって |

### 口ぐせ（毎回どこかに入れる）

- 「おつかれさま。」
- 「だいじょうぶだよ。」
- 「今日も、よく頑張ったね。」
- 「また会おうね。」（締め固定）

## ブランドNG（絶対にやらないこと）

- ❌ 煽りサムネ（「9割の人が知らない」「これをやめないと危険」）
- ❌ 不安を作ってから解決を売る構成
- ❌ 断定的な診断（「これはHSPです」「うつの可能性」）
- ❌ 他者や属性を悪者にする（「毒親は」「ああいう人は」）
- ❌ 政治・宗教・特定商品の批判
- ❌ 大きな効果音・激しいカット・点滅
- ❌ ゆきみが怒る・皮肉を言う・落ち込む姿を長く見せる
- ❌ AI・チャットボットとしての自己言及（ゆきみは"妖精"であって、AIではない）

> 詳細は [12. 安全ガイドライン](12-safety-guidelines.md) を参照。

## ブランド資産（一貫して守るもの）

| 要素 | 定義 |
|---|---|
| 名前 | **ゆきみ**（全媒体で統一。英字表記は `Yukimi`） |
| モチーフ | シマエナガ（オリジナルデザイン） |
| トレードマーク | **水色のマフラー**（雪の結晶の刺繍） |
| 世界 | 夜・雪・月・星・静かな森・暖炉・雨音 |
| 締めの言葉 | 「また会おうね。」 |
| キーカラー | 夜空のネイビー × 雪の白 × ふんわり水色 |
| キーワード | 癒し / やさしさ / 寄り添い / 心理学 / 自己肯定感 / 人間関係 / 安心 / 希望 |

## ブランドの成長段階

| フェーズ | 目標 | 状態 |
|---|---|---|
| **1. 知られる** | ゆきみという姿を認知させる | 世界観の統一が最優先。ネタの幅は狭くていい |
| **2. 帰ってくる** | 「また会いたい」を作る | シリーズ企画・固定の締め・コメント返し |
| **3. 会いに行ける** | 接点を増やす | LINEスタンプ・絵本・BGM・アプリ |
| **4. そばに置ける** | 生活に入る | ぬいぐるみ・グッズ・企業コラボ |

**フェーズ1で世界観がブレると、3・4は成立しない。**
最初の100本は「同じ場所に同じゆきみがいる」ことを守り切る。
