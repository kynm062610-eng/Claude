# 11. 制作フロー

## ツール構成

| 工程 | ツール | 出力 |
|---|---|---|
| ① 企画・台本 | ChatGPT / Claude | `scripts/YYYYMMDD-タイトル.md` |
| ② キャラ画像 | 画像生成AI | `assets/generated/` の静止画 |
| ③ 音声 | ElevenLabs | `audio/YYYYMMDD.mp3` |
| ④ アニメーション | Kling（image-to-video） | 5秒クリップ × 3〜5本 |
| ⑤ 編集 | CapCut | 完成動画（9:16, 30〜35秒） |
| ⑥ 投稿 | 各SNS | — |

---

## 1本を作る手順

### ① 企画・台本（15分）

1. [05. 投稿ネタ100本](05-content-ideas.md) からテーマを1つ選ぶ
2. [04. 動画テンプレート](04-video-template.md) の台本フォーマットに沿って書く
3. [08. 台本ガイド](08-voice-and-script.md) のチェックリストを通す
4. [12. 安全ガイドライン](12-safety-guidelines.md) のチェックリストを通す

**この時点でNGなら、先に進まない。** 後工程が全部無駄になる。

### ② 画像（10分 / 素材があれば0分）

1. **まず `assets/generated/base/` を見る。使える素材があれば生成しない**
2. なければ [06. 画像生成プロンプト](06-image-prompts.md) の組み立て方式で生成
3. [キャラ一貫性チェック9項目](02-character-bible.md#キャラクター一貫性チェック毎回確認)を通す
4. 採用したらシード値を `assets/generated/seeds.md` に記録

### ③ 音声（10分）

1. 台本を ElevenLabs に投入（設定は [08](08-voice-and-script.md#elevenlabs-設定) の固定値）
2. **全部聞く。** 読み間違い・不自然な間があれば台本を直して再生成
3. `audio/` に保存

### ④ アニメーション（20分 / 素材があれば5分）

1. **まず `assets/video/loops/` と `assets/video/endings/` を見る**
2. **締め（④パート）は必ず使い回す**。毎回生成しない
3. 新規が必要な分だけ [07. Kling用プロンプト](07-kling-prompts.md) で生成
4. [Kling採用チェック](07-kling-prompts.md#採用チェックkling出力)を通す

### ⑤ 編集（20分）

CapCut での組み立て：

1. **9:16 / 1080×1920** で新規プロジェクト
2. クリップを配置 → 繋ぎは **クロスフェード 0.3〜0.5秒**
3. 音声を配置。BGMを **-18dB** で下に敷く
4. 字幕：[03. ビジュアルガイド](03-worldview.md#タイポグラフィ) のルールで
   - 丸ゴシック／白文字＋濃紺の縁取り／2行以内／1.2秒以上
   - 位置は画面下から25〜35%
5. 雪のパーティクルを **全体に薄くオーバーレイ**（世界観の統一要素）
6. 冒頭0.3秒・末尾0.5秒に軽いフェード
7. ラウドネス **-14 LUFS** で書き出し

### ⑥ 投稿（10分）

1. [09. SNS運用](09-sns-operations.md) のキャプション・タグを媒体別に用意
2. 4媒体に投稿（1〜2日ずらす）
3. **固定コメントを必ず置く**
4. 重いテーマの回は、概要欄に相談先を記載（→ [12](12-safety-guidelines.md#相談先の案内)）

**所要時間：素材が揃っていれば 1本あたり約60〜75分。**

## 週の回し方（バッチ制作を推奨）

1本ずつ作らない。**工程ごとにまとめて作る**と、はるかに速い。

| 曜日 | 作業 | 内容 |
|---|---|---|
| **日** | 企画 | 翌週5本分の台本をまとめて書く |
| **月** | 素材 | 足りない画像・Klingクリップをまとめて生成 |
| **火** | 音声 | 5本分の音声をまとめて生成（設定を触らずに済む） |
| **水〜木** | 編集 | 5本まとめて編集・書き出し |
| **金** | 予約投稿 | 翌週分を全部予約 |
| 土・日 | — | 休む／コメント返信のみ |

> **常に1週間分のストックを持つ。**
> ストックがゼロになると、焦って世界観がブレた動画を出すことになる。

```
│   │   └── seeds.md            … シード記録
│   └── video/
│       ├── loops/              … 語りベースのループ
│       ├── endings/            … 締めクリップ（全動画共通）
│       └── bg/                 … 背景ループ
├── scripts/                    … 台本（YYYYMMDD-タイトル.md）
├── audio/                      … 音声ファイル
└── published/                  … 投稿済み記録（下記）
```

```markdown

| 2026-08-12 | 001 | 返事が来ない夜に | 人間関係 | 32s | 2.1% | 0.8% | 52% | 「待つ時間」への反応が強い |
```

**保存率トップ5の共通点を、毎月テンプレに反映する。**

## 立ち上げ時の初期作業（一度だけ）

順番に潰していく。

- [ ] **声を決める**（ElevenLabs Voice ID を確定・記録）→ 以後変更しない
- [ ] **基本28カット**を生成（表情7 × シーン4）
- [ ] **締めクリップ**（M6 → M7）を1本作る → 全動画で使い回す
- [ ] **BGM**を3〜5曲確保（商用利用可を必ず確認）
- [ ] **CapCutテンプレート**を作る（字幕スタイル・雪オーバーレイ・フェードを保存）
- [ ] **アカウント4つ開設**（名前・アイコン・プロフィール統一）
- [ ] **パイロット10本**を作りきる
- [ ] 相談先リンクの定型文を用意（概要欄テンプレに登録）

**初期作業を終えてから投稿開始する。** 走りながら作ると必ず世界観がブレる。
