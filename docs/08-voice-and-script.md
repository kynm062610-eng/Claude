# 08. 台本・音声ガイド

## 台本の書き言葉ルール

### 1文の長さ
- **20〜30文字**。長くても40文字まで
- 読点で区切り、息継ぎの位置を作る
- 話速の目安：**1分あたり280〜320字**（一般的なナレーションの約0.8倍）

### ひらがなを多めにする
音声・字幕の両方でやわらかくなる。

| 漢字 | ひらがなにする |
|---|---|
| 大丈夫 | だいじょうぶ |
| 頑張った | 頑張った ※これは漢字のまま（口ぐせとして定着） |
| 貴方 | あなた |
| 事 / 物 | こと / もの |
| 出来る | できる |
| 沢山 | たくさん |
| 尚 / 且つ / 故に | 使わない |

### 語尾のリズム
同じ語尾を3回続けない。

```
❌ 〜だよね。〜だよね。〜だよね。
⭕ 〜だよね。／〜なんだって。／〜かもね。／〜だよ。
```

### 数字・専門用語
- 数字は音で分かりにくいので極力使わない
- 使う場合は読みを台本に併記：`3分（さんぷん）`
- 専門用語は **1本に1つまで**、出したら即座に言い換える

## ElevenLabs 設定

### 声の方向性

| 項目 | 方針 |
|---|---|
| 性別感 | **中性的**。ゆきみに性別はない |
| 年齢感 | 若すぎず、落ち着いた印象 |
| トーン | 低め〜中音域。高いキャラ声にしない |
| 話速 | ゆっくり。急がない |
| 息 | 息づかいが少し聞こえるくらいが良い（近さが出る） |

> **重要**：一度声を決めたら **絶対に変えない**。
> 声はキャラクターの一部。途中で変わるとブランドが壊れる。
> Voice ID を `docs/_voice-id.md` に記録して固定する。

### パラメータ目安

| パラメータ | 値 | 理由 |
|---|---|---|
| Stability | **0.55〜0.65** | 高すぎると平坦、低すぎると回ごとにブレる |
| Similarity | **0.75〜0.85** | 声の一貫性を優先 |
| Style | **0.15〜0.30** | 演技しすぎない。淡々と、やさしく |
| Speaker Boost | ON | 声の同一性が上がる |
| Speed | **0.90〜0.95** | ゆっくりめ |

**Stability を毎回同じ値にすること。** 数値が変わると印象が変わる。

### 間（ま）の作り方

ElevenLabs は句読点で間を作る。台本側でコントロールする。

| 記法 | 効果 |
|---|---|
| `、` | 短い間（0.2秒くらい） |
| `。` | 中くらいの間 |
| `。` + 改行 | 長めの間 |
| `……` | たっぷりの間（共感パートの後に効く） |

```
例：
返信が来ないだけで、こんなに落ち着かないんだね。

……

だいじょうぶだよ。
```

### 読み間違い対策
- カタカナ表記に置き換える（例：`寄り添う` → 問題なし、`所謂` → `いわゆる`）
- 固有名詞は必ずカタカナで（`ゆきみ` はカタカナのままでOK）
- 生成後は **必ず全部聞く**。1箇所でも不自然なら作り直す

## 音声の後処理（CapCut / 編集ソフト）

| 処理 | 設定 |
|---|---|
| ノーマライズ | ピーク -3dB |
| ラウドネス | **-14 LUFS**（SNS標準） |
| 軽いリバーブ | ごく薄く（Room 10%程度）→ 「森の中にいる」感 |
| ノイズ除去 | ONにするなら弱め（かけすぎると声が痩せる） |
| BGMとの差 | ナレーションより **BGMを -18dB 前後** |
| コンプ | 弱め。大きい/小さいの差を潰しすぎない |

**確認方法：スマホのスピーカー最小音量で聞いて、言葉が聞き取れるか。**

## 字幕への落とし込み

音声と字幕は **同じ文章** を使う（ズレると読みづらい）。

| ルール | 内容 |
|---|---|
| 1画面 | **最大2行**、1行12〜16文字 |
| 表示時間 | 最低1.2秒 |
| 改行位置 | 文節で切る。単語の途中で切らない |
| 句読点 | 字幕では省略してよい（読点は改行で代用） |
| 強調 | 太字や色ではなく、**その行だけ単独表示** で強調する |

```
音声：「気にしすぎなんじゃなくて、そういうふうに出来てるだけだよ。」

字幕：
  [1枚目] 気にしすぎなんじゃなくて
  [2枚目] そういうふうに
          出来てるだけだよ
```

## 台本チェックリスト（音声生成前）

- [ ] 1文が40文字以内
- [ ] 同じ語尾が3連続していない
- [ ] 「べき」「しなきゃ」「絶対」が入っていない
- [ ] 専門用語が1つ以内で、言い換えられている
- [ ] 締めが「また会おうね。」で終わっている
- [ ] 全体で30〜35秒に収まる文字数（150〜200字）
- [ ] 読み間違えそうな漢字を潰した
- [ ] [12. 安全ガイドライン](12-safety-guidelines.md) のチェックを通した
