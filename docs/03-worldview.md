# 03. 世界観・ビジュアルガイド

## 世界観の一行

> **静かな夜、雪の降る森の中で、ユキミはあなたを待っています。**

## カラーパレット

| 名前 | HEX | 用途 |
|---|---|---|
| 雪の白 | `#FFFFFF` | ユキミの体・雪・文字 |
| ふんわり水色 | `#B8D4E8` | マフラー・アクセント・光 |
| 夜空のネイビー | `#1B2A4A` | 背景の基調・帯・文字背景 |
| あたたかいオレンジ | `#F0B96B` | ランタン・暖炉・窓明かり |
| やさしいピンク | `#F5C6C6` | チーク・ハート・強調 |
| 森のグレーグリーン | `#8FA396` | 木・影・落ち着かせる面 |

### 配色ルール
- **背景は必ず暗い**（ネイビー系）。白背景は使わない
- **明るい色は"光源"としてのみ使う**（ランタン・月・暖炉・窓）
- 1画面に使う色は **3〜4色まで**
- 彩度は常に低め。ビビッドな色は世界観を壊す
- 赤・紫・蛍光色は使わない（例外：チークのピンクのみ）

## 光の設計

**ユキミの世界は、暗い中に小さな光がある世界。**

| 光源 | 印象 | 使いどころ |
|---|---|---|
| 月 | 静けさ・見守り | 夜の語り・締め |
| 星 | 希望・遠さ | 「また会おうね」 |
| ランタン | ぬくもり・案内 | 導入・寄り添い |
| 暖炉 | 安心・くつろぎ | 疲れた日のテーマ |
| 窓明かり | 帰る場所 | 孤独・帰宅・眠り |

- 光は **背後から** 当てて輪郭を光らせる（リムライト）と、ふわふわ感が出る
- 全体を明るくしない。**暗さを残すことが安心につながる**

## 定番シーン（4種）

キャラクターシートで確定した4つの背景。原則この4つを回す。

| シーン | 内容 | 合うテーマ |
|---|---|---|
| **あたたかい部屋で** | 暖炉のそば、湯気の立つマグカップ | 疲れ・自己肯定感・休むこと |
| **月明かりの森で** | 雪の枝の上、三日月、雪が舞う | 不安・孤独・眠れない夜 |
| **そっと話を聞くよ** | ランタンのそば、雪の中 | 人間関係・恋愛・相談 |
| **雨の日もそばにいるよ** | 窓辺、外は雨、室内はオレンジの明かり | 落ち込み・気分が晴れない日 |

### 拡張シーン（必要になったら）
- 星空を見上げる丘（希望・未来の話）
- 雪の結晶が舞い上がる空（締め専用の画）
- 朝焼けの森（「また明日ね」用・シリーズの節目に）

## 季節と時間

- **基本は"冬の夜"**。年中これでいい（ブランドの識別子になる）
- 季節ネタをやる場合も **雪と夜は残す**（春の夜に薄く雪、など）
- 朝・昼の画は **例外的にのみ**使う（希望や区切りを表すとき）

## 音の設計

| 要素 | 仕様 |
|---|---|
| BGM | ピアノ／オルゴール／アンビエント。テンポ 60〜75BPM |
| 音量 | ナレーションより **明確に小さく**（-18dB目安） |
| 環境音 | 雪・風・薪のはぜる音・雨音・遠い鳥の声 |
| 効果音 | **ほぼ使わない**。使うならキラッという結晶の音のみ、極小音量 |
| 禁止 | 通知音・打撃音・ドラム・急な音量変化・無音からの立ち上がり |

**判定基準：イヤホンで寝落ち視聴して驚かないか。**

## タイポグラフィ

| 用途 | 仕様 |
|---|---|
| 見出し・タイトル | 丸ゴシック系（例：ヒラギノ丸ゴ / Zen Maru Gothic） |
| 字幕 | 太めのゴシック、白文字＋濃紺の縁取りまたは半透明帯 |
| 文字サイズ | スマホ縦画面で **1行 12〜16文字**まで |
| 行数 | 同時表示は **最大2行** |
| 禁止 | 明朝の細字（スマホで読めない）・派手なアニメーション・赤文字 |

### 字幕ルール
- 1文＝1表示。読点で改行しない、文で切る
- 表示時間は **最低1.2秒**。速いカットは世界観を壊す
- 画面下から1/4の位置に固定（アプリUIに隠れない高さ）

## 画面レイアウト（9:16）

```
┌─────────────────┐  ← 上部15%：UIに隠れる。何も置かない
│                 │
│                 │
│    ユキミ        │  ← 中央〜やや下：ユキミの定位置
│                 │
│                 │
├─────────────────┤
│    字 幕         │  ← 下から25〜35%の帯
├─────────────────┤
│                 │  ← 下部15%：UIに隠れる。何も置かない
└─────────────────┘
```

- ユキミは **画面の中心よりやや下**。上部に余白（＝空）を残すと世界が広く見える
- ユキミは常に **カメラ側を向いている**（視聴者と目が合う）

## 動きのルール

- **カメラはほぼ動かさない**。動かすなら極めてゆっくりズームイン
- カットは **1本あたり3〜5カット**まで。切り替えはクロスフェード
- 雪・光の粒子は **常にゆっくり降らせる**（世界観の統一要素）
- ユキミの動き：まばたき、首をかしげる、羽を小さく動かす、風でマフラーが揺れる
- **禁止**：素早い動き・飛び回る・振り向きの高速カット・画面の揺れ

## 世界観チェックリスト

- [ ] 背景が暗く、光源が1〜2個ある
- [ ] 雪または光の粒子がゆっくり舞っている
- [ ] 色数が4色以内、彩度が低い
- [ ] ユキミが画面中央〜やや下にいて、こちらを向いている
- [ ] 字幕が2行以内、1.2秒以上表示されている
- [ ] BGMが小さく、驚く音がない
- [ ] 見終わったあと「静かだった」と感じる
