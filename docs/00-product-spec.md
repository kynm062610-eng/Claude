# こうかんノート — プロダクト仕様書

小学生（およそ 8〜12 歳）向けの、グループ制交換ノートアプリ。

- 対象プラットフォーム: iOS / Android（Expo / React Native）
- バックエンド: Supabase（Auth / Postgres / Realtime / Storage）
- 想定グループ規模: 3〜6 人

---

## 1. コンセプト

紙の交換ノートの「順番に回す」体験をそのままアプリにする。加えて、書くことに詰まった子が離脱しないよう **お題ガチャ** を組み合わせる。

| 要素 | 内容 |
|---|---|
| 回覧ノート型（土台） | 3〜6 人のグループで 1 冊のノートを順番に回す。自分の番になったら通知が届き、書いたら次の子へ回る |
| お題カード型（補助） | 「今日のお題」をアプリが配る。何を書けばいいか分からない子の入口 |

**設計の芯**: ノートは「みんなで 1 冊を育てるもの」であり、SNS ではない。フォロー・検索・DM・タイムラインは作らない。

### やらないこと（MVP 以降も含め、意図的に持たない機能）

- ユーザー検索、フレンド申請、DM
- カメラ撮影・写真アップロード（顔・場所が写り込むため）
- 位置情報の取得
- 公開タイムライン、いいね数のランキング表示
- 外部リンクの埋め込み、アプリ内ブラウザ

## 2. 中心となる概念

```
Guardian（保護者）
  └── Child（子どもプロフィール / ニックネーム＋アバターのみ）
        └── Membership ──── Group（招待コードでのみ参加、最大 6 人）
                              └── Notebook（1 冊 ＝ ページの連なり）
                                    └── Page（1 人が 1 回書く単位）
                                          ├── Reaction（絵文字のみ）
                                          └── Report（通報）
```

### 回覧ルール

1. ノートには **順番（turn order）** がある。参加順で決まり、グループ作成者が並べ替えできる。
2. 書き込めるのは **現在の番の子だけ**。ほかの子は読むことしかできない。
3. ページを提出すると順番が次の子へ移り、次の子にプッシュ通知が飛ぶ。
4. 3 日書かれないと、グループの誰でも「かえして！」を 1 日 1 回だけ送れる（催促も遊びにする）。
5. 現在の番の子は「パスする」を選べる（体調不良・多忙時の逃げ道。パスは記録に残さない）。

### ページの中身

- 手書き描画レイヤー（指で描く。小学生にキーボード必須は厳しい）
- テキスト（ふりがな切り替え対応）
- スタンプ（貼り付け位置・大きさ・回転を保持）
- 便箋の背景柄

ページはベクタ的な JSON（ストローク列 ＋ 要素配置）として保存し、表示用に PNG のサムネイルを Storage に置く。JSON を残すのは、あとから拡大表示・再編集・印刷用の高解像度書き出しを可能にするため。

## 3. MVP スコープ

### 入れるもの

| # | 機能 | 補足 |
|---|---|---|
| 1 | 保護者登録 → 子どもプロフィール作成 | メールは保護者のみ。子どもはニックネーム＋アバター |
| 2 | グループ作成 / 招待コードで参加 | 6 文字コード。最大 6 人 |
| 3 | ノート一覧・ページ閲覧 | 誰の番かが一目で分かる |
| 4 | ページ作成（描画＋テキスト＋スタンプ＋背景） | 自分の番のときだけ |
| 5 | 絵文字リアクション | 自由コメントは MVP では持たない（荒れやすいため） |
| 6 | 「次の子の番だよ」プッシュ通知 | Expo Push |
| 7 | 見まもりモード（3 段階） | → `01-safety-and-privacy.md` |
| 8 | NG ワード検知・通報・ブロック | ストア審査の必須要件 |

### 入れないもの（フェーズ 2 以降）

- 着せ替え（マステ・フォント・シール収集）
- ノート完成時のアルバム化 / PDF 書き出し / 印刷
- 音声メモ
- 2 人同時編集の合作ページ
- お題ガチャの拡張（MVP は固定のお題プールから日替わりで 1 問）

## 4. 画面一覧

| 画面 | 役割 |
|---|---|
| `onboarding/guardian` | 保護者のメール登録・同意取得 |
| `onboarding/child` | ニックネーム＋アバター選択（ひらがな入力） |
| `home` | 所属グループ一覧。「あなたの番」バッジ |
| `group/[id]` | ノートのページ一覧（本棚風）。招待コード表示 |
| `group/join` | 招待コード入力 |
| `page/[id]` | ページ閲覧＋リアクション＋通報 |
| `page/new` | ページ作成（描画キャンバス） |
| `settings` | ふりがな切り替え、通知、見まもりモードの表示 |
| `guardian/console` | 保護者用。見まもりモード設定、開示請求、退会 |

---

## 5. UI 方針

- **全画面ふりがな切り替え可**。初期値は「ひらがな多め」。
- タップ対象は最小 56dp。低学年の指でも押せる大きさ。
- 破壊的操作（削除・退会）は保護者コンソール側にのみ置く。
- エラー文は責めない言い方にする（「まちがえちゃった？ もういちどためしてみよう」）。
- 夜 21:00〜翌 6:00 は書き込み画面を開けない（保護者が時間帯を変更可）。

## 6. 技術構成

| 層 | 選定 | 理由 |
|---|---|---|
| アプリ | Expo (React Native) + expo-router | iOS/Android 同時、開発速度 |
| 描画 | `@shopify/react-native-skia` | 指描きの追従性。ストロークをそのまま保持できる |
| 認証 | Supabase Auth（保護者のメール） | 子ども自身はメールを持たない前提 |
| DB | Supabase Postgres + RLS | 行レベルでグループ外の閲覧を遮断 |
| 画像 | Supabase Storage | ページのサムネイル PNG |
| 通知 | Expo Push Notifications | |

データモデルと RLS は `02-data-model.md` を参照。
