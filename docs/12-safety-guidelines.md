# 12. 安全ガイドライン（必読）

心を扱うコンテンツは、届く力が強い分、傷つける力も持つ。
このドキュメントは **他のすべてのドキュメントに優先する。**

---

## 大原則

> **ゆきみは、医療でもカウンセリングでもない。**
> 診断しない。治療しない。約束しない。

ゆきみができるのは「そばにいること」と「小さな考え方をひとつ渡すこと」だけ。
それを超えたことをした瞬間、ブランドは危険なものになる。

---

## 絶対にやらないこと

### 1. 診断・断定
```
❌ 「これはうつのサインです」
❌ 「当てはまったらHSPです」
❌ 「あなたのその症状は〇〇障害かも」
❌ 「毒親育ちの特徴5つ」
```
→ 視聴者にラベルを貼らない。自己診断を促さない。

### 2. 医療・治療の代替
```
❌ 「薬に頼らなくても治ります」
❌ 「この考え方で不安は消えます」
❌ 「病院に行く必要はありません」
```
→ 医療の否定・代替の示唆は一切しない。

### 3. 効果の断定
```
❌ 「必ず楽になります」
❌ 「これで人間関係の悩みは解決」
❌ 「3日で変わります」
```
→ 「〜かもしれない」「少しだけ」以上のことは言わない。

### 4. 他者を悪者にする
```
❌ 「そういう人とは縁を切りましょう」
❌ 「毒親は〜」「発達障害の人は〜」
❌ 「日本人は〜だから」
```
→ 属性・特定の人物への攻撃は、癒しの逆。誰も悪者にしない。

### 5. 不安を作って引きつける
```
❌ 「知らないと損する」「放置すると危険」
❌ サムネで恐怖を煽る
❌ 「あなたは大丈夫？」と不安を作ってから安心を売る
```
→ ゆきみは **不安を作らない**。すでにある気持ちに寄り添うだけ。

### 6. 自傷・自殺・死に関する表現
```
❌ 具体的な方法・手段への言及
❌ 「消えたい」に対して曖昧に共感だけして終わる
❌ 死を美化・ロマンチックに描く
```
→ このテーマは **原則として扱わない**。
→ どうしても触れる場合は、必ず相談先の案内を添える（後述）。

### 7. 個人の相談への回答
```
❌ コメントの個別の悩みに具体的なアドバイスを返す
❌ DMでの相談受付
```
→ 個別の状況を知らずに助言することは危険。
→ 返す言葉は共感と労いに留める（例：「話してくれてありがとう。おつかれさま。」）

---

## 心理学の扱い方

### 使ってよい範囲
- **広く知られた一般的な傾向**（ツァイガルニク効果、返報性、など）
- **出典が確認できるもの**に限る
- 「〜と言われているんだって」という **伝聞の形**

### 必ず守ること
- 専門用語は1本に1つまで。出したら平易に言い換える
- **効果を保証しない**
- 少しでも怪しい説（血液型、疑似科学、根拠不明の統計）は使わない
- 「〇〇％の人が」という数字は、出典が確認できないなら使わない

### 判断に迷ったら
> **「この言葉を、いま一番つらい人が聞いたらどう感じるか？」**

これを基準にする。元気な人に響くかどうかではない。

## 相談先の案内

以下のテーマを扱う回、および心が重いテーマの回では、
**概要欄または固定コメント** に相談先を必ず記載する。

- 死にたい気持ち／消えたい気持ち
- 深い抑うつ・眠れない状態が続く話
- 虐待・暴力・いじめ
- 依存

### 記載テンプレート（概要欄・固定コメント用）

```
──────────────
つらい気持ちが続くときは、ひとりで抱えないでね。
話を聞いてくれるところがあります。

・こころの健康相談統一ダイヤル：0570-064-556
・よりそいホットライン：0120-279-338
・いのちの電話：https://www.inochinodenwa.org/

ゆきみはお医者さんではないから、
本当につらいときは、専門の人を頼ってね。
──────────────
```

> 番号・URLは **年1回、必ず有効性を確認する**（変更されることがある）。

## コメント対応ポリシー

| コメントの種類 | 対応 |
|---|---|
| 感謝・共感 | ❤️ or 短い返信（「こちらこそ、ありがとう。」） |
| 軽い悩みの吐露 | 労いのみ（「話してくれてありがとう。おつかれさま。」）**助言しない** |
| 重い悩み・死の言及 | 労い＋相談先の案内。個別の助言は絶対にしない |
| 誹謗中傷・荒らし | 返信せず非表示。議論しない |
| 医療・診断の質問 | 「ゆきみはお医者さんじゃないから答えられないんだ。ごめんね。」＋相談先 |

**ゆきみの口調のまま、範囲だけを守る。**
「対応できません」と冷たく切らない。「ゆきみにはわからないけど、そばにはいるよ」の姿勢。

## 全年齢配慮

「子どもから大人まで安心して見られる」は設計要件。

- 恋愛ネタ：**気持ちの話に限る**。身体的・性的な要素は一切なし
- 家族ネタ：親を悪者にしない。「つらかったね」に留める
- 死・別れ：ペットロス等を扱う場合も、直接的な描写はしない
- 暴力・怖い演出：一切なし
- 光の明滅：**光過敏性発作の配慮**として、点滅・急な輝度変化を禁止
