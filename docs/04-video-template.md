# 04. 動画テンプレート

## 基本構成（4部）

| # | パート | 役割 | 秒数 | 文字数目安 |
|---|---|---|---|---|
| ① | **共感する一言** | 「私のことだ」と思わせる | 0:00〜0:05 | 20〜35字 |
| ② | **やさしい物語・心理学** | なぜそうなるのかを、やわらかく | 0:05〜0:20 | 90〜130字 |
| ③ | **今日できる小さな考え方** | 持ち帰れるものを1つだけ | 0:20〜0:28 | 40〜60字 |
| ④ | **「また会おうね」** | 締め・再訪の約束 | 0:28〜0:32 | 15〜25字 |

**総尺：30〜35秒。上限40秒。**
語りは **1分あたり280〜320字** の遅さ（通常のナレーションより明確にゆっくり）。

## 各パートの書き方

### ① 共感する一言（0〜5秒）

**目的**：スクロールを止める。ただし煽らない。

書き方：
- **状況** ＋ **気持ち** ＋ **「〜だよね」**
- 質問形にしない（「〜な人いませんか？」は広告っぽい）
- 断定して、視聴者を主語にしない（「あなたは疲れています」はNG）

```
⭕ 「なんでもない日なのに、涙が出そうな夜ってあるよね。」
⭕ 「返信が来ないだけで、こんなに落ち着かないんだね。」
⭕ 「頑張ったのに、誰にも気づかれない日。」

❌ 「9割の人が知らない心理学」
❌ 「これをやめないと人生損します」
❌ 「あなたはHSPかもしれません」
```

### ② やさしい物語・心理学（5〜20秒）

**目的**：「そうなるのには理由があるんだ」と安心してもらう。

書き方：
- 専門用語は **1本に1つまで**。出したら必ず言い換える
- 「〜という心理があるんだって」と **伝聞の形**にすると押し付けにならない
- **原因を人のせいにしない**（自分のせいにもしない）
- 「だから、あなたが悪いわけじゃないよ」に着地させる

```
例（返信が気になる日）：
「人の心はね、答えが返ってこない時間が、いちばん苦手なんだって。
 だから、返事を待つ時間って、実際より長く感じるんだ。
 気にしすぎなんじゃなくて、そういうふうに出来てるだけなんだよ。」
```

### ③ 今日できる小さな考え方（20〜28秒）

**目的**：持ち帰れるものを **1つだけ** 渡す。

書き方：
- **行動 or 考え方をひとつだけ**。2つ言うと何も残らない
- ハードルを極端に下げる（「1分だけ」「1回だけ」「今日はやらなくていい」）
- 「〜してみてもいいかもね」の許可の形にする

```
⭕ 「今日はね、"返事は明日でいい"って決めちゃおう。」
⭕ 「ノートに一行だけ、今日できたことを書いてみて。」
⭕ 「なにもしない、を今日の予定にしていいよ。」

❌ 「毎日3つのことを習慣にしましょう」（多い・命令）
```

### ④ また会おうね（28〜32秒）

**目的**：再訪の約束。**毎回同じ形にする。**

固定フォーマット：
```
「今日も、よく頑張ったね。
 また会おうね。」
```

バリエーション（締めの最後は必ず「また会おうね。」）：
- 「おやすみ。また会おうね。」
- 「ゆっくり休んでね。また会おうね。」
- 「あなたはひとりじゃないよ。また会おうね。」

**画**：雪の結晶が舞い上がる → ユキミが小さく手（羽）を振る → 暗転

## 台本フォーマット

制作時はこの形式でファイルを作る（`scripts/YYYYMMDD-タイトル.md`）。

```markdown
# [第○回] タイトル

- **カテゴリ**：人間関係
- **投稿予定**：2026-08-12（火）21:30
- **尺**：32秒
- **シーン**：月明かりの森で
- **一言テーマ**：返事が来ない夜

---

## ① 共感（0:00-0:05）｜表情：おつかれさま…
> 返信が来ないだけで、こんなに落ち着かないんだね。

- 画：枝の上、雪がゆっくり降る。カメラ固定
- 字幕：2行

## ② 物語・心理学（0:05-0:20）｜表情：考え中… → だいじょうぶだよ
> 人の心はね、答えが分からない時間がいちばん苦手なんだって。
> だから、待っている時間は、本当より長く感じるんだ。
> 気にしすぎなんじゃなくて、そういうふうに出来てるだけだよ。

- 画：ゆっくりズームイン
- 字幕：1文ずつ、3枚

## ③ 小さな考え方（0:20-0:28）｜表情：にっこり
> 今日はね、「返事は明日でいい」って決めちゃおう。
> それだけで、夜が少しやさしくなるよ。

- 画：ランタンの光がふわっと強くなる

## ④ 締め（0:28-0:32）｜表情：うれしい！
> 今日も、よく頑張ったね。
> また会おうね。

- 画：雪の結晶が舞い上がる → 羽を振る → 暗転

---

## メタ情報
- **タイトル案**：返事が来ない夜に、読んでほしい話
- **ハッシュタグ**：#ユキミ #心理学 #癒し #シマエナガ #おやすみ
- **サムネ文字**：返事、まだかな
- **固定コメント**：今日はどんな一日だった？ユキミが聞くよ。
```

## 派生テンプレート

### A. 30秒スタンダード（上記）
デフォルト。全体の70%はこれ。

### B. 15秒ショート（口ぐせ型）
- ① 共感（0-4秒）→ ④ 締め（4-15秒）
- 心理学パートを省き、**言葉だけを届ける**
- 「おつかれさま」だけを言う回。定期的に挟むと世界観が濃くなる

### C. 60秒ストーリー
- 森の中の小さな出来事を通して伝える寓話型
- ① 共感 → ②' 物語（30秒）→ ③ 考え方 → ④ 締め
- 月1〜2本。ファン向け。保存されやすい

### D. 静止＋BGM（3〜10分）
- ユキミがそばにいるだけの睡眠用・作業用
- YouTube本体向け。視聴時間を稼ぎ、収益化の土台になる

## 尺と数字の目安

| 指標 | 目標 |
|---|---|
| 冒頭2秒の離脱 | 40%未満 |
| 完全視聴率 | 45%以上 |
| 保存率 | 1.5%以上（癒し系は保存が主KPI） |
| コメント率 | 0.5%以上 |

**再生数より「保存」と「コメント」を見る。**
「また会いたい」を作れているかは、その2つに出る。
