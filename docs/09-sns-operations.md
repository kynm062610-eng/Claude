# 09. SNS運用

## 「投稿セット」コマンド（2026-08-17〜）

**「投稿セット」と声をかけられたら、直近の台本に対して以下7点を毎回この順番・この形式でコピペ用に出力する。**

1. YouTube Shorts タイトル
2. YouTube Shorts 説明文
3. YouTube Shorts タグ
4. Instagram Reels キャプション文
5. Instagram Reels タグ
6. TikTok キャプション文
7. TikTok タグ

- 読点は使わない（→ [08](08-voice-and-script.md#読点について重要2026-08-12)）
- タグは**媒体ごとに設計が違う**（→ [ハッシュタグ設計](#ハッシュタグ設計2026-08-17-全面改訂)）。同じタグを3媒体に使い回さない
- どの台本が対象か曖昧なときは、最新の台本ファイルを使う。不明なら確認する
- 説明文には台本の①②③の要旨と固定コメントの文言を含める。④の「また会おうね」で締める

## 媒体の役割分担

同じ動画を4媒体に出すが、**役割は違う**。

| 媒体 | 役割 | 主な狙い |
|---|---|---|
| **YouTube** | **本拠地・資産** | 長尺BGM／収益化の土台／検索で見つかる |
| **TikTok** | **入口** | 新規リーチ最大。ここで知られる |
| **Instagram Reels** | **世界観** | ビジュアルで刺さる。グッズ・IP展開との相性が最高 |
| **X (Twitter)** | **日常の接点** | 一言＋画像で毎日会える。ファンとの距離が近い |

### アカウント統一
- 名前：**ゆきみ**（全媒体で完全に同一）
- ID：`@yukimi_` 系で統一（取得可能なものに揃える）
- アイコン：正面・にっこりのゆきみ（**全媒体同一画像**）
- ヘッダー：月明かりの森
- プロフィール文（共通）：

```
シマエナガの妖精・ゆきみ🤍
今日より少しだけ、心が軽くなる30秒。
おつかれさま。だいじょうぶだよ。
毎日21:30 / また会おうね。
```

## 投稿設計

### 投稿時間

| 媒体 | 時間 | 理由 |
|---|---|---|
| YouTube Shorts | **21:30** | 帰宅後〜就寝前 |
| TikTok | **22:00** | 夜のピーク |
| Instagram Reels | **21:00** | Reelsは少し早め |
| X | **7:30 / 22:30**（1日2回） | 朝の見送り＋夜の労い |
| 「眠れない夜に」シリーズ | **0:00**（金曜） | ターゲットが確実にいる時間 |

### 投稿頻度（推奨ペース）

| フェーズ | 本数 | 内訳 |
|---|---|---|
| 立ち上げ（1〜3ヶ月） | **週5本** | 30秒×4 ＋ 15秒×1 |
| 安定期 | **週5〜7本** | ＋ 月2で60秒ストーリー、月1でBGM長尺 |
| 無理な時 | **週3本** | 落とすなら本数。**質と世界観は落とさない** |

> **毎日投稿を目標にしない。** 世界観が崩れた1本は、休んだ1日より損失が大きい。

### 縦持ちの原則
- **完全に同じ動画を4媒体に出してよい**（ロゴ焼き付けはしない）
- ただし **1〜2日ずらす**（同時投稿だと各プラットフォームで評価が割れる場合がある）
- TikTokのロゴ入り動画を他媒体に転載しない（リーチが落ちる）

## ハッシュタグ設計（2026-08-17 全面改訂）

> **旧ルール（全SNS共通で同じ5個）は誤り。** 3媒体で仕様がまったく違う。
> さらに `#癒し` `#心理学` のような巨大タグは、立ち上げ期のアカウントでは
> 数秒で埋もれるため実質的に効果がない。**小〜中規模タグで上位表示を狙う。**

### 媒体ごとの前提（調査結果）

| 媒体 | タグの仕様 | 設計方針 |
|---|---|---|
| **Instagram** | **2025年12月から5個が上限**（6個以上でエラー、またはリンクにならない） | ミドル2＋スモール2＋ブランド1 |
| **YouTube** | タグの影響力は限定的。2026年はLLMが音声・テロップ・映像を直接解析 | **類語・表記ゆれを拾わせる補助**として使う |
| **TikTok** | 検索エンジン化が進行。**キャプション本文のキーワードのほうが効く** | 共感系（#あるある）を混ぜる。タグは5個前後 |

### YouTube Shorts

タグ欄（類語・表記ゆれで検索を拾う。ブランドタグを並べない）
```
ゆきみ, シマエナガ, 癒し動画, 寝る前に見る動画, 疲れた時に見る動画,
心が軽くなる言葉, 自己肯定感, メンタルケア, ヒーリング, おやすみ, shorts
```

説明文のハッシュタグは **3個まで**（タイトル上に表示されるのは3個）
```
#ゆきみ #癒し #shorts
```

### Instagram Reels（5個厳守）

```
#ゆきみ #シマエナガ #自己肯定感 #心が軽くなる言葉 #疲れた心に
```

- `#ゆきみ` … ブランド（固定）
- `#シマエナガ` `#自己肯定感` … ミドル
- `#心が軽くなる言葉` `#疲れた心に` … スモール（**ここで上位表示を取る**）
- テーマに応じてスモール2個を差し替える

### TikTok

```
#ゆきみ #シマエナガ #あるある #寝る前に見る #自己肯定感
```

- **キャプション本文に検索されるキーワードを入れる**ことがタグより重要
- `#あるある` は日本のTikTokで強い共感系タグ。ゆきみの4部構成①と相性が良い

### 未検証事項（要確認）

各タグの**実際の投稿数はアプリ内でしか確認できない**。以下を実測して更新する。

- [ ] Instagram検索で上記5個の投稿数を確認
- [ ] 1万〜50万＝ミドル、1万以下＝スモールとして振り分け直す
- [ ] スモール枠が50万超だったら別のタグに差し替える
- [ ] 3ヶ月ごとに再確認（タグの規模は変動する）

## コミュニティ運営

### 固定コメント（毎回置く）
```
今日はどんな一日だった？
よかったら、ここに置いていってね。
ゆきみが、そっと聞くよ。
```
→ **コメントを増やす最強の仕掛け**。「気持ちを置いていく場所」にする

### 「雪の結晶」企画（月2回）
コメントで寄せられた気持ちを、ゆきみが雪の結晶に変えて空へ返す回。
- コメントは **匿名化して要約**（原文をそのまま出さない）
- 重い内容は使わない（→ [12. 安全ガイドライン](12-safety-guidelines.md)）
- 「自分のコメントが届いた」体験が、最強のファン化装置になる

### コメント返信ルール
- 返すのは **ゆきみの口調**（運営としての「です・ます」は使わない）
- 助言はしない。労いと共感だけ
- 全部返さなくていい。**返せる範囲で、丁寧に**
- 対応方針の詳細は [12. 安全ガイドライン](12-safety-guidelines.md#コメント対応ポリシー)

## KPI（見る数字）

### 主要指標

| 指標 | なぜ見るか | 目標 |
|---|---|---|
| **保存率** | 「また見たい」の直接指標。癒し系の本命 | 1.5%以上 |
| **コメント率** | 「会いに来ている」かどうか | 0.5%以上 |
| **完全視聴率** | 30秒最後まで見たか | 45%以上 |
| **リピート視聴** | ファン化の指標 | 上昇傾向 |
| フォロワー転換率 | 見た人がどれだけ残るか | 1%以上 |

### 見なくていい数字
- 単発のバズ再生数（世界観と無関係に伸びることがある）
- インプレッション総数

> **判断基準：再生数が伸びた回ではなく、"保存された回"を分析する。**
> 保存される回＝「もう一度、この気持ちの時に会いに来たい」回。

### 月次レビュー項目
1. 保存率トップ5の共通点は？（カテゴリ／時間帯／表情／シーン）
2. 離脱が早かった回の①（共感の一言）は何が弱かった？
3. コメントで多かった気持ちは？ → 次月のネタに反映
4. 世界観がブレた回はなかったか？（→ ブレたなら原因を記録）

## 運用カレンダー（週次の型）

| 曜日 | 内容 | シリーズ |
|---|---|---|
| 月 | 自己肯定感 | 週の始まりの労い |
| 火 | 人間関係 | — |
| 水 | ストレス・不安 | — |
| 木 | 15秒「今日のおつかれさま」 | 短尺 |
| 金 | 睡眠・夜（0:00投稿） | **眠れない夜に** |
| 土 | 自由枠／月2で「ゆきみの森の話」 | 60秒ストーリー |
| 日 | 休み（Xのみ一言投稿） | — |

**日曜は休む。** 続けることが最大の資産なので、休みを設計に入れる。

## 立ち上げ手順（最初の1ヶ月）

1. **アカウント4つ開設** — 名前・アイコン・プロフィールを完全統一
2. **ストック10本を作りきってから投稿開始**（走りながら作らない）
3. 最初の2週間は **世界観の統一だけを見る**。数字は見ない
4. 3週目から保存率を計測開始
5. 1ヶ月後：伸びた回の共通点を洗い出し、テンプレを更新する

> 最初の10本で世界観が固まれば、あとは同じ場所に同じゆきみがいるだけでいい。
