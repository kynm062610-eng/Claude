# 09. SNS運用

## 媒体の役割分担

同じ動画を4媒体に出すが、**役割は違う**。

| 媒体 | 役割 | 主な狙い |
|---|---|---|
| **YouTube** | **本拠地・資産** | 長尺BGM／収益化の土台／検索で見つかる |
| **TikTok** | **入口** | 新規リーチ最大。ここで知られる |
| **Instagram Reels** | **世界観** | ビジュアルで刺さる。グッズ・IP展開との相性が最高 |
| **X (Twitter)** | **日常の接点** | 一言＋画像で毎日会える。ファンとの距離が近い |

### アカウント統一
- 名前：**ゆきみ**（全媒体で完全に同一）
- ID：`@yukimi_` 系で統一（取得可能なものに揃える）
- アイコン：正面・にっこりのゆきみ（**全媒体同一画像**）
- ヘッダー：月明かりの森
- プロフィール文（共通）：

```
シマエナガの妖精・ゆきみ🤍
今日より少しだけ、心が軽くなる30秒。
おつかれさま。だいじょうぶだよ。
毎日21:30 / また会おうね。
```

## 投稿設計

### 投稿時間

| 媒体 | 時間 | 理由 |
|---|---|---|
| YouTube Shorts | **21:30** | 帰宅後〜就寝前 |
| TikTok | **22:00** | 夜のピーク |
| Instagram Reels | **21:00** | Reelsは少し早め |
| X | **7:30 / 22:30**（1日2回） | 朝の見送り＋夜の労い |
| 「眠れない夜に」シリーズ | **0:00**（金曜） | ターゲットが確実にいる時間 |

### 投稿頻度（推奨ペース）

| フェーズ | 本数 | 内訳 |
|---|---|---|
| 立ち上げ（1〜3ヶ月） | **週5本** | 30秒×4 ＋ 15秒×1 |
| 安定期 | **週5〜7本** | ＋ 月2で60秒ストーリー、月1でBGM長尺 |
| 無理な時 | **週3本** | 落とすなら本数。**質と世界観は落とさない** |

> **毎日投稿を目標にしない。** 世界観が崩れた1本は、休んだ1日より損失が大きい。

### 縦持ちの原則
- **完全に同じ動画を4媒体に出してよい**（ロゴ焼き付けはしない）
- ただし **1〜2日ずらす**（同時投稿だと各プラットフォームで評価が割れる場合がある）
- TikTokのロゴ入り動画を他媒体に転載しない（リーチが落ちる）

## ハッシュタグ設計

**全SNS共通で合計5個に固定（2026-08-12〜）。** それ以上は付けない。

### 固定タグ（毎回・3個）
```
#ゆきみ #シマエナガ #癒し
```
→ ブランド検索の受け皿。**必ず全投稿につける**

### テーマタグ（回ごとに2個）
その回の内容から最も合うものを2個だけ選ぶ。

```
#心理学 #自己肯定感 #人間関係 #ストレス #不安 #恋愛 #親子関係
#おやすみ #眠れない夜 #メンタルケア #寝る前に見る
```

**固定3個＋テーマ2個＝5個。** それ以上絞れないときは、いちばんそのタイトルに近い2個を選ぶ。

## コミュニティ運営

### 固定コメント（毎回置く）
```
今日はどんな一日だった？
よかったら、ここに置いていってね。
ゆきみが、そっと聞くよ。
```
→ **コメントを増やす最強の仕掛け**。「気持ちを置いていく場所」にする

### 「雪の結晶」企画（月2回）
コメントで寄せられた気持ちを、ゆきみが雪の結晶に変えて空へ返す回。
- コメントは **匿名化して要約**（原文をそのまま出さない）
- 重い内容は使わない（→ [12. 安全ガイドライン](12-safety-guidelines.md)）
- 「自分のコメントが届いた」体験が、最強のファン化装置になる

### コメント返信ルール
- 返すのは **ゆきみの口調**（運営としての「です・ます」は使わない）
- 助言はしない。労いと共感だけ
- 全部返さなくていい。**返せる範囲で、丁寧に**
- 対応方針の詳細は [12. 安全ガイドライン](12-safety-guidelines.md#コメント対応ポリシー)

## KPI（見る数字）

### 主要指標

| 指標 | なぜ見るか | 目標 |
|---|---|---|
| **保存率** | 「また見たい」の直接指標。癒し系の本命 | 1.5%以上 |
| **コメント率** | 「会いに来ている」かどうか | 0.5%以上 |
| **完全視聴率** | 30秒最後まで見たか | 45%以上 |
| **リピート視聴** | ファン化の指標 | 上昇傾向 |
| フォロワー転換率 | 見た人がどれだけ残るか | 1%以上 |

### 見なくていい数字
- 単発のバズ再生数（世界観と無関係に伸びることがある）
- インプレッション総数

> **判断基準：再生数が伸びた回ではなく、"保存された回"を分析する。**
> 保存される回＝「もう一度、この気持ちの時に会いに来たい」回。

### 月次レビュー項目
1. 保存率トップ5の共通点は？（カテゴリ／時間帯／表情／シーン）
2. 離脱が早かった回の①（共感の一言）は何が弱かった？
3. コメントで多かった気持ちは？ → 次月のネタに反映
4. 世界観がブレた回はなかったか？（→ ブレたなら原因を記録）

## 運用カレンダー（週次の型）

| 曜日 | 内容 | シリーズ |
|---|---|---|
| 月 | 自己肯定感 | 週の始まりの労い |
| 火 | 人間関係 | — |
| 水 | ストレス・不安 | — |
| 木 | 15秒「今日のおつかれさま」 | 短尺 |
| 金 | 睡眠・夜（0:00投稿） | **眠れない夜に** |
| 土 | 自由枠／月2で「ゆきみの森の話」 | 60秒ストーリー |
| 日 | 休み（Xのみ一言投稿） | — |

**日曜は休む。** 続けることが最大の資産なので、休みを設計に入れる。

## 立ち上げ手順（最初の1ヶ月）

1. **アカウント4つ開設** — 名前・アイコン・プロフィールを完全統一
2. **ストック10本を作りきってから投稿開始**（走りながら作らない）
3. 最初の2週間は **世界観の統一だけを見る**。数字は見ない
4. 3週目から保存率を計測開始
5. 1ヶ月後：伸びた回の共通点を洗い出し、テンプレを更新する

> 最初の10本で世界観が固まれば、あとは同じ場所に同じゆきみがいるだけでいい。
