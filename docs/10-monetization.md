# 10. 収益化導線

## 大前提

> **収益化のために世界観を曲げない。**
>
> ユキミは「心に寄り添う存在」。その信頼だけが資産であり、
> 信頼が壊れた瞬間に、すべての収益源が同時に消える。

### 絶対にやらないマネタイズ
- ❌ 不安を作って商品を売る（「このままだと危険」→ 教材販売）
- ❌ 心理カウンセリング・診断サービスの販売
- ❌ 高額情報商材・サロン
- ❌ ユキミが商品を勧めるステマ
- ❌ 効果を保証する健康・メンタル系商品のPR
- ❌ 動画中に唐突に挟む広告訴求

### 守るルール
- 収益要素は **動画の外**（概要欄・プロフィール・固定コメント）に置く
- 動画本編は **最後まで、ただ寄り添うだけ**
- PRは必ず明示（`#PR`）。かつ **世界観に合うものだけ** 受ける

## フェーズ設計

```
フェーズ1: 基盤        →  フェーズ2: IP化      →  フェーズ3: 事業化
（0〜6ヶ月）              （6〜18ヶ月）            （18ヶ月〜）
広告 + アフィリエイト      グッズ + デジタル商品     ライセンス + 企業
```

## フェーズ1：基盤（0〜6ヶ月）

**目標：まず「会いに来る人」を作る。収益はおまけ。**

### 1-A. プラットフォーム広告収益

| 媒体 | 条件 | 備考 |
|---|---|---|
| YouTube パートナープログラム | 登録者1,000人＋Shorts視聴1,000万回（90日） | **長尺BGM動画が近道** |
| TikTok | 各種クリエイタープログラム（要件は変動） | 単価は低い |
| Instagram | ボーナス施策があれば | 安定しない |

> **長尺BGM動画（10〜60分）が収益化の最短ルート。**
> 静止画＋ユキミの微モーション＋BGM＋雪。作るコストが低く、視聴時間が長い。
> Shortsで知ってもらい、長尺で滞在してもらう構造を作る。

### 1-B. アフィリエイト（世界観に合うものだけ）

概要欄・プロフィールリンクに置く。**ユキミ本人には言わせない。**

| 商品カテゴリ | 適合度 |
|---|---|
| 睡眠グッズ（アイマスク・枕・加湿器） | ◎ |
| ハーブティー・ホットドリンク | ◎ |
| 間接照明・ランタン・アロマ | ◎ |
| ヒーリング音楽・オーディオブック | ○ |
| 心理学の一般書 | ○ |
| メンタル系サプリ・健康食品 | **✗ 扱わない** |
| カウンセリングサービス | **✗ 扱わない** |

記載例（概要欄）：
```
──────────────
ユキミの部屋にあるもの
・あたたかいマグカップ  →  [リンク]
・やわらかい間接照明    →  [リンク]
※アフィリエイトリンクを含みます
──────────────
```

### 1-C. 投げ銭・サポート
- YouTube メンバーシップ／Super Thanks
- TikTok ギフト
- **note / BOOTH の「ユキミを応援する」枠**

「支援」ではなく **「ユキミにあたたかい飲みものを」** のような世界観の言い回しにする。

## フェーズ2：IP化（6〜18ヶ月）

**目標：画面の外でも会えるようにする。**

### 2-A. LINEスタンプ（最初のグッズ）

- **初期投資ほぼゼロ／制作が早い／ブランド認知が広がる**
- 40個セット。表情7種 × 口ぐせで作れる
- 収録すべき言葉：
```
おつかれさま / だいじょうぶだよ / 今日もよく頑張ったね / また会おうね
ありがとう / ごめんね / おやすみ / いってらっしゃい / おかえり
了解だよ / 無理しないでね / 聞いてるよ / うれしい / ぎゅっ
```
> **口ぐせがそのままスタンプになる。** ブランド設計とグッズが一直線に繋がる。

### 2-B. デジタル商品

| 商品 | 内容 | 価格帯 |
|---|---|---|
| **睡眠BGMアルバム** | ユキミの森の音＋ピアノ、60分 | 500〜1,500円 |
| **壁紙・スマホ待受セット** | 4シーン × 季節版 | 300〜800円 |
| **デジタル絵本** | 「ユキミの森のはなし」PDF/EPUB | 800〜1,500円 |
| **メンバーシップ** | 限定の「おやすみボイス」週1配信 | 月300〜500円 |

販路：BOOTH / note / Gumroad / YouTubeメンバーシップ

### 2-C. 絵本（物理）

- 「ユキミの森の話」シリーズを本にする
- 全年齢設計が効いてくる。**親子で読める**のが強み
- 最初は電子＋POD（オンデマンド印刷）でリスクを抑える
- 反応が良ければ出版社に持ち込む

### 2-D. ぬいぐるみ・グッズ

- **需要が確認できてから**。在庫リスクが大きい
- クラウドファンディング（CAMPFIRE / Makuake）で先に検証する
- 優先順：ぬいぐるみ ＞ マフラー（実物）＞ アクリルスタンド ＞ マグカップ
- **水色マフラーが再現できているかが命**

## フェーズ3：事業化（18ヶ月〜）

### 3-A. アプリ

| 機能案 | 内容 |
|---|---|
| 今日の気持ちを置く | 一言書くと、ユキミが結晶にして空へ返す |
| おやすみモード | ユキミが見守る画面＋BGM、タイマー付き |
| 毎日の一言 | 朝と夜に、ユキミの言葉が届く |
| きろく | 「今日できたこと」を一行だけ書く場所 |

> **注意**：AIチャット機能を入れる場合、
> ユキミは「AIです」と名乗らない世界観だが、**サービスとしてはAI利用を明示する義務がある。**
> 「ユキミとお話しする（AIを使っています）」のように、アプリ側の表記で誠実に開示すること。
> また、相談窓口の常設表示が必須（→ [12. 安全ガイドライン](12-safety-guidelines.md)）。

### 3-B. 企業コラボ

**受けてよい業種**
- 寝具・睡眠 / 飲料（ハーブティー等）/ 照明・インテリア
- 自治体（観光・北海道／シマエナガ）/ 書店・出版
- 福祉・教育（子ども向け）

**受けない業種**
- 医療・サプリで効果を訴求するもの
- 金融・投資・副業
- 転職・キャリア煽り系
- ダイエット・美容の不安訴求系

**コラボの形式**
- ユキミが商品を「勧める」のではなく、**世界に商品が"ある"** 形にする
  - 例：「ユキミの部屋に、あたたかい飲みものが届いたよ。」

### 3-C. ライセンス

- キャラクターライセンス（雑貨・食品パッケージ）
- 自治体・鉄道・施設とのタイアップ
- **ここまで来ると、ブランドガイドライン（本リポジトリ）がそのまま提供資料になる**

## 収益ミックスの目標像（18ヶ月後）

| 収益源 | 比率イメージ |
|---|---|
| 長尺BGM＋Shorts広告 | 30% |
| デジタル商品（BGM・絵本・壁紙） | 25% |
| グッズ・LINEスタンプ | 20% |
| メンバーシップ | 15% |
| 企業コラボ・ライセンス | 10% |

**単一依存を避ける。** プラットフォームのアルゴリズム変更で全部が消えないようにする。

## 導線設計（視聴者が辿る道）

```
TikTok / Reels で出会う
        ↓
「また会いたい」と思う（保存・フォロー）
        ↓
YouTube の長尺BGMで、そばに置く（滞在時間 → 広告収益）
        ↓
LINEスタンプで、日常に連れて行く
        ↓
グッズ・絵本で、生活の中に置く
        ↓
アプリで、毎日会いに来る
```

各段階で **「押し売りされた」と感じさせない**。
ユキミは常に「そこにいるだけ」で、視聴者が自分から近づいてくる形にする。

感じるなら、やらない。それだけ。
