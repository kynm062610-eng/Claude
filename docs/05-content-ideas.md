## ネタ出しの型（100本を超えたら）

新しいネタは、この掛け算で作る。

```
【いつ】 朝 / 通勤 / 昼休み / 帰り道 / 夜 / 眠る前 / 休日 / 連休明け
   ×
【誰と】 ひとり / 職場 / 友だち / 家族 / 好きな人 / SNSの向こう
   ×
【気持ち】 疲れ / 不安 / 寂しさ / 焦り / 罪悪感 / むなしさ / 怒れなさ / 小さな喜び
```

例：`連休明け × 職場 × 焦り` → 「連休明けの朝、体が重いよね。」

**判定基準**：そのネタを、今いちばんつらい人が見て傷つかないか。
（→ [12. 安全ガイドライン](12-safety-guidelines.md)）
