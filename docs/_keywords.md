# 検索キーワード実測メモ

**推測で書かない。YouTubeのサジェスト（検索候補）で実測したものだけを記録する。**

## 実測方法

1. YouTubeアプリの検索窓にテーマの言葉を入力する
2. 入力途中に下へ出てくる候補（サジェスト）をそのまま書き写す
3. **サジェストに出る＝実際に検索されている言葉**

## ★ 実測から分かったこと

### 曜日で検索価値があるのは「日曜」だけ

**月曜・火曜は天気・ドラマ・英語しか出ない。** 誰も曜日そのものの気持ちを検索していない。
**日曜の夜だけが「眠れない」「憂鬱」「吐き気」と結びついている。**

実績と一致：

| 回 | タイトルの曜日 | 検索流入 |
|---|---|---|
| 003 | **日曜の夜** | **3.5%** |
| 013 | 火曜の夜 | 1.8% |

### したがって

**曜日ネタは「投稿時刻」で効かせ、タイトルには曜日を書かない。**

```
❌ 火曜日がしんどい｜いちばん踏ん張ってる場所にいるよ
⭕ 眠れない夜に｜いちばん踏ん張ってる場所にいるよ
```

例外：**日曜だけはタイトルに入れる価値がある。**

### 「眠れない」が主戦場

候補の数と幅が突出している。
[05. 投稿ネタ](05-content-ideas.md) の「睡眠・夜」カテゴリ15本を、ここに全部当てられる。
