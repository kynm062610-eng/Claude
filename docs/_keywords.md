# 検索キーワード実測メモ

**推測で書かない。YouTubeのサジェスト（検索候補）で実測したものだけを記録する。**

## 実測方法

1. YouTubeアプリの検索窓にテーマの言葉を入力する
2. 入力途中に下へ出てくる候補（サジェスト）をそのまま書き写す
3. **サジェストに出る＝実際に検索されている言葉**

## 実測結果（2026-08-19）

### ⭕⭕ 最優先（感情の検索しか出ない）

**頑張れない**（★今回の最良発見）
```
頑張れない
頑張れない時
頑張れないんじゃなくて頑張りすぎただけ
頑張れない人
頑張れない心で何が起きているか
```
**5件すべてが感情の検索。翻訳・辞書系がゼロなのはこの語だけ。**
「頑張れないんじゃなくて頑張りすぎただけ」は**そのままゆきみのセリフになる実在の検索語**。

**眠れない**（候補の幅が最大）
```
眠れない / 眠れない時 / 眠れない夜 / 眠れない原因 / 眠れない ストレス
眠れない 病院 / 眠れない 脳の病気 / 眠れない なぜ
眠れないまま朝になった 知恵袋
```

**日曜の夜**（曜日で唯一使える）
```
日曜の夜 眠れない / 日曜の夜 憂鬱 / 日曜の夜 ぐらいは
日曜の夜 くらいは / 日曜の夜 吐き気
```

### ⭕ 使える

**人間関係**
```
人間関係 疲れた
人間関係に疲れたら
人間関係 めんどくさい
人間関係 うまくいかない
人間関係リセット症候群
```
※「英語」「占い」も出るが、感情側が多数派。**「人間関係」は前置きとして機能する。**

### △ 半分だけ使える

**自己肯定感**
```
⭕ 自己肯定感 上げる方法
⭕ 自己肯定感 低い
❌ 自己肯定感 とは
❌ 自己肯定感 読み方
❌ 自己肯定感 英語
```
**「とは」「読み方」「英語」＝調べもの層。** 気持ちを軽くしたい人ではない。
使うなら **「上げる方法」「低い」の2つだけ。** 単体の「自己肯定感」はタイトルに置かない。

### ❌ 使えない

**疲れた（単体）**
```
疲れた 英語 / 疲れた 韓国語 / 疲れた 顔文字 / 疲れた 言い換え / 疲れた 中国語
```
**5件すべて翻訳・変換の検索。** 気持ちで検索している人はいない。
→ **「疲れた」を単体でタイトルに置くのは無意味。**
　必ず前の語とセットにする（⭕「人間関係 疲れた」）。

**月曜**
```
月曜 天気 / 月曜 英語 / 月曜 ドラマ / 月曜 ドラマ 2026 / 月曜 映画 安い
```

**火曜日**
```
火曜日 英語 / 火曜日 英語 略 / 火曜日 ドラマ / 火曜日 天気 / 火曜日 ドラマ一覧
```

## ★ 実測から分かった法則

### 法則1：単語だけの感情語は「翻訳」に食われる

「疲れた」「自己肯定感」のような**短い一般語は、辞書・翻訳・意味調べの検索に占領されている。**
気持ちで検索している人に届くのは、**状態を表す長い言い方**のほう。

```
❌ 疲れた          → 英語・韓国語・顔文字
⭕ 頑張れない       → 5件すべて感情
⭕ 人間関係 疲れた   → 感情
⭕ 眠れない        → 感情
```

**タイトルに置く語は「文になっているか」で選ぶ。**

### 法則2：曜日で検索価値があるのは「日曜」だけ

月曜・火曜は天気・ドラマ・英語しか出ない。誰も曜日そのものの気持ちを検索していない。

実績と一致：

| 回 | タイトルの曜日 | 検索流入 |
|---|---|---|
| 003 | **日曜の夜** | **3.5%** |
| 013 | 火曜の夜 | 1.8% |

→ **曜日ネタは「投稿時刻」で効かせ、タイトルには曜日を書かない。日曜のみ例外。**

```
❌ 火曜日がしんどい｜いちばん踏ん張ってる場所にいるよ
⭕ 頑張れない時に｜いちばん踏ん張ってる場所にいるよ
```

## ★★ 媒体別の実測（2026-08-19）｜同じ語でも目的が違う

**「眠れない」で検索している人は、YouTubeとTikTokで別人。**

### YouTube｜「聞く」ための検索

```
眠れない時に聞く曲   ← 1番目
眠れない
眠れない時
眠れない夜を抱いて
眠れない時に聞く話   ← ★ゆきみそのもの
眠れない夜
眠れないんだ風もなくなりそうな
```

**症状を調べていない。寝ながら流すものを探している。**

### TikTok｜「治す」ための検索

```
眠れない スピリチュアル
眠れない 辛い
眠れない 病院
眠れない なぜ
眠れない 吐き気
眠れない 薬
眠れない 漢方
眠れない 対処
眠れない 歌詞
眠れない夜を抱いて zard
```

**病院・薬・漢方・対処＝解決策を探している。**
ゆきみの「そのままでいいよ」はここには刺さらない。

### したがって

| 媒体 | 「眠れない」で戦うか | 使う語 |
|---|---|---|
| **YouTube** | **戦う** | `眠れない時に聞く話` `眠れない夜` `眠れない時` |
| **TikTok** | **戦わない** | `頑張れない` `人間関係 疲れた` に寄せる |

**全媒体で同じタグ・同じタイトルを使わない。**

## ★ 確定したタイトルの型（2026-08-19）

```
眠れない時に聞く話｜◯◯◯◯◯
```

**「検索語を入れる」より強い。** 検索結果でそのままクリックされる形になっている。

さらに `聞く話` は **長尺（10分以上）に展開できる**。
→ [10. 収益化](10-monetization.md) の「長尺が収益化の最短ルート」に直結する。

**ショートで反応を測り、当たった話を長尺にまとめる**という流れが作れる。

## 使う語の優先順位（この順で消化する）

| 順 | 語 | 根拠 |
|---|---|---|
| 1 | **頑張れない / 頑張れない時** | 感情検索100% |
| 2 | **眠れない時に聞く話 / 眠れない夜 / 眠れない時** | YouTube限定。候補の幅が最大 |
| 3 | **人間関係 疲れた / 人間関係に疲れたら** | 感情が多数派 |
| 4 | **日曜の夜 憂鬱 / 日曜の夜 眠れない** | 日曜限定・実績あり |
| 5 | 自己肯定感 低い / 上げる方法 | この2語のみ |

[05. 投稿ネタ](05-content-ideas.md) の各カテゴリを、この5枠に割り当てていく。
