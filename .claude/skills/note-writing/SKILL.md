# note運用スキル（2026年9月時点の情報ベース）

Web検索で集めたnoteの伸ばし方をまとめたもの。半年〜1年経ったら`WebSearch`で再確認してから使うこと。

## 無料記事と有料記事の比率

- 無料記事だけだとフォロワーは増えにくく、有料記事だけだと読者がつかない。
- 目安は**無料70〜80% : 有料20〜30%**。まず無料記事で読者を増やし、後から有料記事に誘導する流れが基本。
- 今のフォロワー0の段階では、無料記事オンリーでOK。有料化はフォロワーが育ってから。

## タイトル・SEO戦略

- 2026年のnote SEOは「検索意図にちゃんと答えていて、読んで楽しい記事」が評価される。
- 競合の激しい一語のビッグキーワードより、**3語以上の組み合わせ（ロングテール）**を狙う方が
  現実的（例：「トラック運転手 副業 動画編集」）。
- タイトルには検索されそうな言葉を入れる。あいまいなタイトルは検索に引っかからない。
- 更新頻度が低すぎるとGoogleに再訪問されにくくなる。ペースはゆるくてもいいから途切れさせない。

## 投稿後48時間が勝負

- 公開直後〜48時間のアクティビティ（閲覧・スキ・コメント）がその後の評価に大きく影響する。
- 投稿したらすぐX/Instagram/Threadsでシェアして、初速をつけるのが効果的
  （`sns-writing`と組み合わせて、note公開の告知投稿もセットで作る）。

## noteの内部アルゴリズム（フォロワーを増やす仕組み）

- noteは「動く人（活発なユーザー）」に有利にできている。投稿数・スキ・コメントなど
  直近のアクティビティ量が多いほど、おすすめ・急上昇タグや人気記事一覧に載りやすい。
- 「書く → 見られる → さらに書く」の好循環を作るのが基本戦略。最初は数を出して
  露出の機会を増やすのが有効。

## アイキャッチ画像（見出し画像）

- 見出し画像はほぼ必須級。あるとないとでクリック率が2〜3倍変わるというデータもある。
  特にSNSでシェアされた時の見た目に直結するので、必ず設定する。
- 推奨サイズ：**1280×670px**
- 顔出しNGなので、以下のような画像が向いている：
  - トラックの運転席・荷台・街並みなど、顔が映らない雰囲気写真
  - タイトルをそのままデザインしたテキスト画像（Canvaなどで数分で作成可）
  - noteの「みんなのフォトギャラリー」（無料の写真素材、note内で使える）

## ハッシュタグ戦略

- 投稿数が数十万件クラスの「メガタグ」を1〜2個 ＋ ニッチで検索意図の合うタグ、の組み合わせが黄金比。
- よく使われる汎用タグの例（2026年9月時点の投稿数目安）：#日記（500万件超）、#エッセイ（200万件超）、
  #毎日note（170万件超）。ジャンルに合わせて、副業・トラック運転手系のニッチタグも組み合わせる。

## プレミアムプランについて

- 投稿頻度が増えたり、複数テーマで発信したくなったタイミングで検討でOK。
  マガジン機能（テーマ別に記事を整理）や予約投稿が使えるようになる。今は無料プランで十分。
