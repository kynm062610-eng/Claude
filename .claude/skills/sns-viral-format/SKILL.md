# SNSプラットフォーム別「バズる投稿の型」（毎回ライブ検索）

このスキルには具体的な型を書き込まない。理由はシンプルで、バズる型は数ヶ月単位で
入れ替わるから。呼ばれるたびに以下の手順で最新情報を取りに行くこと。

## 手順

1. ユーザーがどのプラットフォームを聞いているか特定する（X / Instagram / Threads / TikTok /
   複数まとめて、など）。曖昧なら聞く。
2. `WebSearch`で、現在の年を使って以下のようなクエリを投げる（年は必ず今の年に置き換える）。
   - `X (Twitter) 投稿 バズる 型 <年>`
   - `Instagram 投稿 バズる フォーマット <年>`
   - `Threads 投稿 伸びる 型 <年>`
   日本語だけでなく英語クエリ（例: `viral X post format <year>`）も併用すると情報量が増える。
3. 結果から「型（構成のパターン）」を抽出して、プラットフォームごとに短くまとめる。
   - 冒頭の作り方（フック）
   - 文の長さ・構成の順番
   - 画像/動画の有無、テキストの入れ方
   - ハッシュタグ・リンクの扱い
4. 出典リンクを必ず添える（CLAUDE.mdのルール通り）。
5. 「これはWeb検索時点の情報で、数ヶ月で変わりうる」旨を一言添える。

## 注意

- 記憶にある古い情報（例: 2023年頃のバズり方の常識）だけで答えない。必ずこのターンで検索する。
- 複数プラットフォームを聞かれたら、プラットフォームごとに型を分けて出す（ごちゃ混ぜにしない）。
- `video-script`（動画の台本構成）や`sns-writing`（文章の書き方の基礎）と組み合わせて、
  「型が分かったら実際の投稿文/台本を書く」流れにつなげてよい。
