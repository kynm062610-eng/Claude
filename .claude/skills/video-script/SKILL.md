# 動画台本・構成スキル（2026年9月時点の情報ベース）

Web検索で集めた最新の台本設計セオリーをまとめたもの。トレンドは変わりやすいので、
半年〜1年経ったら`WebSearch`で再確認してから使うこと。

## 長尺（YouTube 10分前後）

**離脱の実態**
- 離脱の50〜60%は最初の3秒で起きる。最初の3秒を超えた視聴者の65%は10秒まで到達する。
- 台本を作ってる channel は平均40〜60%の視聴維持率、アドリブ中心は25〜35%。差が出る。

**基本構成**
```
フック（0〜10秒）→ セットアップ → 価値提供（本編）→ ペイオフ（回収）→ CTA
```
- 60〜90秒おきに「パターンインタラプト」（話題転換・カメラ切替・音の変化など）を入れると、
  平均視聴時間が15〜25%伸びるという報告あり。
- 動画の中間地点（50%）にも再フックを仕込む。

**分量の目安**
- 話す速度は130〜150 words/分（日本語ならもっと文字数は変わるので目安として）。
- 10分の動画なら英語換算で1,300〜1,500 wordsが目安。台本を書きすぎ（20〜30%オーバー）
  が離脱を招くので、詰め込みすぎない。

**書き方のコツ**
- フルで台本を書いた後、しゃべる時は「箇条書きのキーワード台本」に変換して覚えると自然に話せる。
- 会話調で書く。「です・ます」の説明文調より、話し言葉に近い方が刺さる。

## ショート（YouTube Shorts / TikTok / Reels）

**フックが全て**
- 2026年時点、最初の2秒で惹きつけられなければ即離脱される。冒頭15秒の「バイラルフック」が
  動画全体を決めると言われている。
- 「こんにちは」「今日は〜について話します」のような前置きは厳禁。いきなり本題・結論から入る。

**フック構造の型（効果が高い順の目安）**
1. 大胆な主張（Bold claim） — 一番効果高い
2. 好奇心ギャップ（Curiosity gap） — 「答えが気になる」状態を作る
3. ミニストーリー導入
4. ビジュアルショック
5. 直接的な質問

**【最重要・毎回必ず徹底】具体的な数字・意外な事実を冒頭0〜3秒に必ず置く**
「本業の合間に副業を始めました」のような自己紹介・前置きから入らない。台本の中に
インパクトある具体的事実（金額、件数、期間などの数字）がある場合は、それを一番最初の
セリフに持ってくる。まず数字や意外性で「なんで？」を作ってから、背景・文脈を後付けで
説明する順番に必ず組み替えること。台本を作るたびにこのチェックを行う。

**分量**
- 30秒のショートなら70〜110語程度が目安（短いセリフの積み重ね）。全体は35〜220語のレンジ。

**字幕は必須**
- 85%は無音で最初に視聴される。字幕なしはフックが伝わらず即離脱。

**ループ設計**
- ラストをオープニングに戻る形にする（クリフハンガー・ループ構造）と再生数が伸びやすい。

## 基本構成（共通テンプレ）
```
フック → セットアップ → 価値提供・見せ場 → ペイオフ → CTA
```
長尺・ショート共通で使えるベース構造。長尺は各ブロックを厚く、ショートは極限まで削る。
