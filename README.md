# こうかんノート

小学生（およそ 8〜12 歳）向けの、グループ制交換ノートアプリ。
3〜6 人で 1 冊のノートを順番に回し、自分の番が来たら手書き・スタンプ・テキストでページを書く。

Expo (React Native) + Supabase。

安全設計の要点は 3 つ。

1. **保護者の「同意」と「閲覧」を分ける。** 法が求めるのは同意であって監視ではない。閲覧は初期値 OFF。
2. **見まもりモードを子どもの画面に常時表示する。** こっそり読める設計を作らない。モード変更は本人に通知される。
3. **モードに関わらず安全フロアは常時作動する。** NG ワード検知・通報・運営によるモデレーション。

## セットアップ

```bash
npm install
cp .env.example .env      # Supabase の URL と anon key を記入
npm start
```

Supabase 側は `supabase/migrations/0001_init.sql` を適用する。
匿名サインインを使うため、Supabase の Auth 設定で Anonymous sign-ins を有効にすること
（子ども端末は保護者とセッションを分ける設計のため）。

```bash
npm test          # ユニットテスト（node:test）
npm run typecheck # tsc --noEmit
```

## 構成

```
app/                     expo-router の画面
  index.tsx              起動時の振り分け
  onboarding/            保護者登録・子ども端末のコード入力
  home.tsx               グループ一覧（「あなたの番」バッジ）
  group/                 グループ詳細・招待コードでの参加
  notebook/[id].tsx      ページ一覧、書く／パスする／かえして！
  page/new.tsx           描画エディタ（投稿前の NG ワード判定はここ）
  page/[id].tsx          ページ閲覧、リアクション、通報、ブロック
  profile/edit.tsx       自分のプロフィール編集
  profile/[childId].tsx  プロフィール閲覧（自分／仲間）
  settings.tsx           子ども向け設定（ひらがな／かんじ切り替えなど）
  guardian/console.tsx   保護者メニュー（見まもりモード、開示請求）
src/
  api/                   Supabase 呼び出し
  moderation/            NG ワード・個人情報の判定
  features/canvas/       Skia の描画キャンバス
  features/tree/         みんなで育てる木（成長段階の計算と描画）
  components/            共通 UI、見まもりバッジ、保護者操作の通知バナー

  utils/                 夜間制限、順番の計算

```

## 実装済み（MVP）

- 保護者登録と同意記録（同意文言のバージョンを保存）
- リンクコードによる子どもプロフィールの受け渡し（子どもは独立した匿名 auth ユーザー）
- グループ作成・招待コード参加（最大 6 人）・回覧順
- ノートのページ一覧、ページ作成（手書き／テキスト／スタンプ／便箋の柄）
- 「自分の番のときだけ書ける」を RLS と RPC の両方で担保
- パスする、かえして！（3 日経過後・1 日 1 回）
- 絵文字リアクション、通報（2 件で自動非表示）、ブロック
- 投稿前の NG ワード・個人情報判定と、保護者への安全通知（本文は送らない）
- 自傷を示す表現（死にたい 等）は他人への攻撃とは別カテゴリで扱い、責めずに相談を促す
- 見まもりモード 3 段階、子ども画面への常時表示、変更時の本人通知
- 開示請求（閲覧 OFF でも行使可能）
- 夜間の書き込み制限
- ひらがな／かんじ表示の切り替え（中学生・高校生の利用も想定）
- プロフィール（好きなもの・性格・面白い質問など）。自由入力欄は投稿と同じ NG ワード判定を通す。
  居住地・生年月日・写真・恋愛に関する質問は意図的に用意しない
- みんなで育てる木。ノートのページが増えるほど育ち、季節で見た目が変わる。
  個人の連続記録は条件にせず、減らない・枯れない。課金とも結びつけない
