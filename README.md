# ユキミ プロジェクト

> **今日より少しだけ心が軽くなる30秒。**

シマエナガの妖精「ユキミ」を中心にした、癒し系ショート動画ブランドの設計リポジトリ。

心理学を"教える"のではなく、**「ユキミに会いに来る場所」**をつくることを目的にしています。
落ち込んだ日や、疲れた夜に、少しだけ心が軽くなる時間を届けます。
