# 長距離ドライバー 8,000字 構成書

参考動画（17:13）を実測分解し、そこから逆算した8,000字シナリオの設計。
ジャンルは**日常密着・淡々系モノローグ**。事件も伏線もオチも要らない型。

| 項目 | 値 |
|---|---|
| 本文 | 8,000字 |
| 推定尺 | 25.6分 |
| 話速 | 312字/分 |
| 参考動画比 | 1.49倍 |

## 2. この型の解剖

1. **事件が起きない。そして解決もしない。**
   山場は「2分遅れで嫌味を言われる」だけ。復讐も謝罪もなく、担当者が上司に詰められるのを遠くから見るだけで終わる。溜飲を下げすぎない止め方。踏み外すとスカッと系に変質する。

2. **数字が骨格。形容詞を使わない。**
   70cm／手取り25万／月12日／200円3分／80円／20kg×200個／2分／15分／298円／3秒。
   しんどさもうれしさも全部数字で出す。密度は**150字に1個**。8,000字なら**50〜55個**必要。

3. **全編が「70cm ⇔ 6畳」の対比で貫かれている。**
   同じ要素を前半（車中）と後半（自宅）で必ず二度出す。説明ゼロで感情を運ぶ最大の仕掛け。

4. **飯が主役。クライマックスは食事シーン。**
   味噌汁80円 → おにぎり350円 → 鮭カマ298円。後半3分は完全に飯動画。

5. **セリフが極端に短く、感情を説明しない。**
   会話は6往復すべて1行。地の文で気持ちを解説する行が1行もない。

6. **独り言が地の文に混ざってリズムを作る。**
   「よし」「うるせえ」「いてえ」「やべえな、これ」「抜いてけ、抜いてけ」。

7. **リフレインで印象を固定する。**
   「仙台から直送して、1週間寝かせて、炙って」×2。「この音だよ」×2。

8. **オチない。成長も救済もない。**
   「明後日の田楽のことを考えてる時点で、多分まだ大丈夫だ」。続いていくことだけを肯定して終わる。

### 感情曲線はJ字

W字ではない。前半でじわじわ削られ、⑨伝票待ちで底を打ち、⑬宴で一気に振り切る。
⑤走行だけが前半唯一の上昇点で、「それでもこの仕事が嫌いじゃない」を担保している。
**ここを削ると全体がただの愚痴になる。**

## 4. 尺の伸ばし方

**事件を足してはいけない。** この型の視聴者が見に来ているのは展開ではなく生活のディテール。
増やすのは解像度であって、出来事の数ではない。

### やってはいけない伸ばし方

- **事件を2つ入れる**（渋滞＋パンク、トラブル連発）→ 物語調になり「淡々」が壊れる
- **主人公の過去を語らせる**（離婚、借金、諦めた夢）→ 感動系という別ジャンルに変質。参考動画は過去を一切語らない
- **荷主に復讐する／謝らせる** → スカッと系になる。「上司に詰められているのを見る」で止める抑制がジャンルの生命線
- **教訓・説教を入れる**（「物流は社会を支えている」等）→ 最も嫌われる着地。主人公は一度も自分の仕事を意義づけない
- **同じ描写の水増し** → 「狭い」を3回書くのではなく、狭さの別の実害（着替え、荷物の置き場、冬の結露）を出す

| 06 | +260 | ルート判断の根拠。プロの頭の中を見せる |

## 6. 文体ルール

朗読前提。参考動画の語り口を踏襲するための具体ルール。

- 一人称は**「俺」**。常体。現在形と過去形を意図的に混在させる（実況と回想が同居する語り）
- 一文**25〜30字**を基本。40字を超えたら切る。読点は多めでいい
- 独り言をカギカッコなしで地の文に混ぜる：「よし」「うるせえ」「いてえ」「やべえな、これ」
- 会話は**1行1発言**。地の文で気持ちを解説しない。「〜と言われて悔しかった」は禁止
- **感情語を使わない。** つらい・うれしい・悔しいと書かず、数字と行動で出す
- 「たくさん」「かなり」「すごく」を**全部具体値に置換**。数量・金額・分数・個数・センチ
- 体言止めを多用してリズムを作る：「70cm。」「200円、3分。」「150個。あと50。」
- 各パートに**リフレインを1つ**。同じフレーズを二度置く
- 擬音を書かない。音は**状況で描く**（「ジュー」ではなく「この音だよ」）
- 締めの一行は**解決させない。**「多分まだ大丈夫だ」の温度。断定も悲観もしない

### 数字の density チェック

参考動画は5,376字に約35個＝**150字に1個**。8,000字なら**50〜55個**が目標値。
書き上げたら数えて、足りなければ「たくさん」を数字に置換して埋める。
この密度がこのジャンルの品質そのもの。
