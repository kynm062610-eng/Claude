# ナレーション台本 ／ 画像番号別・話者別

CapCutでテキスト読み上げする際、[ ]の中のタグに応じて声を変えてください。
タグなしの地の文・父のセリフは「主人公（ナレーター）」の声のままでOKです。

## 声の割り当て（4種類）

| タグ | 役 | 声の目安 |
|---|---|---|
| なし | 主人公（地の文＋父のセリフ） | 40代男性・低め・落ち着いた声（デフォルト） |
| [娘] | 長女・次女（共通） | 子どもの声。次女のセリフは少し高め・元気に読むと差が出しやすい |
| [妻] | 妻 | 30代後半女性・穏やかな声 |
| [山本] | 山本さん | 50代男性・やや高め・申し訳なさそうな声 |
