# 育児 × 発達障害 SNS参入リサーチ（Instagram / Threads）

調査日: 2026-08-13 / 出典は各セクション末尾に記載

---

## 0. 結論（先に）

**やる価値はある。ただし「体験談マンガ」で入ると勝てない。**

- 需要側（親の母数・悩みの深さ・お金の動く導線）は明確に伸びている。ニッチではあるが「困りごとの深さ」が桁違いで、フォロワー単価が高いジャンル。
- 一方でInstagramの「発達障害×育児マンガ」は**すでに10万フォロワー級が複数いる成熟レッドオーシャン**。同じ土俵は不利。
- 空いているのは **①学齢期以降（就学・進路・二次障害）②父親／夫婦視点 ③診断前グレーゾーンの「動き方」実務**。
- Threadsは**日本で今いちばん地合いが良い**（利用時間が前年比2.3倍、返信数重視のアルゴリズム）。悩み相談ジャンルとアルゴリズムの相性が構造的に良く、**Threads起点 → Instagramで資産化**が現時点の最適解。

## 1. 需要（マーケットサイズ）

| 指標 | 数値 | 備考 |
|---|---|---|
| 通常学級で発達障害の可能性がある小中学生 | **8.8%**（約11人に1人） | 文科省2022年調査。2012年比 **+2.3pt** |
| 障害児通所支援の利用児童 | **約45.7万人** | 令和7年1〜3月時点 |
| └ 放課後等デイサービス | **約37.5万人** | 2012年制度創設時 約5万人 → **7倍以上** |
| └ 児童発達支援 | **約15.1万人** | 平成24年度比 **3.2倍** |

読み取れること:

1. **母数が大きい。** 8.8%は「診断済み」ではなく「グレーゾーン含む」の数字で、これがそのまま**"診断はないけど困っている親"という最大ボリューム層**の存在を示す。ここが情報に最も飢えている。
2. **市場は10年で数倍に膨張中。** 事業者側（放デイ・児発・塾・オンライン相談）が急増＝**広告主・タイアップ・提携先が増え続けている**＝収益化の受け皿がある。
3. **悩みのフェーズが明確に分かれている。** 研究上、親のニーズは「気づきの困難期 → 診断前後の不安期 → 具体的な養育支援期 → 就学支援期」に分かれる。つまり**フェーズを絞ればコンテンツが即座に差別化できる**。
4. **二次障害（不登校・抑うつ・適応障害）が親の最大の恐怖。** 検索・相談需要の中でも切迫度が最も高い＝保存・DM共有されやすいテーマ。

> 出典: [文科省調査(日経)](https://www.nikkei.com/article/DGXZQOUE0891U0Y2A201C2000000/) / [放デイ利用者数推移](https://kensei-fukushi.jp/blog/) / [児発 市場動向](https://coconova.or.jp/child-development-entry/) / [親支援研究(井上雅彦, 厚労科研)](https://mhlw-grants.niph.go.jp/system/files/2016/162091/201616026A_upload/201616026A0007.pdf) / [二次障害(LITALICOジュニア)](https://junior.litalico.jp/column/article/054/)

## 2. プラットフォーム分析

### 2-1. Threads（今の狙い目）

| 項目 | 内容 |
|---|---|
| 月間アクティブ | **5億超**（2026年6月・Meta公式） |
| 日本の利用時間 | **前年比130%超成長 = 1年で2.3倍** |
| 日本の利用実態 | 利用者の**約7割が1日30分以内**／**20代の約3割が毎日利用** |
| アルゴリズム | **いいねより「返信数（建設的な会話）」を最重要指標**として評価 |
| 2026年の新機能 | コミュニティ機能が正式版化、「Your Algo」でユーザーがフィードを調整可能 |

**このジャンルにとっての意味:**

- 返信数が最重要 → **「うちもです」「うちはこうでした」が自然に湧くジャンルは構造的に有利。** 育児×発達障害は日本のSNSで最も返信が集まりやすいテーマのひとつ。
- テキスト主体 → **顔出し・作画・撮影が一切いらない。** 参入コストがほぼゼロで、子どものプライバシーも守りやすい。
- スキマ時間運用が前提の設計 → **当事者育児中でも回せる**（実際に育休中に開始して短期で成果を出した事例が複数報告されている）。
- 日本の伸び率がグローバル平均より高く、**まだ先行者利益が残っている**（Instagramの育児ジャンルにはもう残っていない）。

> 出典: [Meta公式(5億人)](https://about.fb.com/ja/news/2026/06/meta-launching-new-features-500-million-monthly-threads-users/) / [MarkeZine 3周年](https://markezine.jp/article/detail/77127) / [Threads利用実態調査2026](https://www.commercepick.com/archives/90497) / [Threads伸ばし方ガイド](https://tatap.jp/knowledge/how-to-extend-threads/)

### 2-2. Instagram（資産化・収益化の場）

2026年時点のアルゴリズム要点:

- **リールは「視聴維持率」と「シェア率」が最重視。** 冒頭3秒での離脱防止が最大の鍵。推奨尺は **15〜60秒**（3分超は非フォロワーリーチが激減）。
- **DM共有が最も高く評価される。** 「誰かに送りたい」＞「いいね」。
  → このジャンルは**「これ、うちの夫／実母／担任に読ませたい」**が発生する。DM共有と極めて相性が良い。
- **保存**の重要度も上昇。就学準備リスト、面談で使える言い換え表など**"あとで使う"情報**が刺さる。
- リール限定でフォロワー数によらず公平に評価される改善が入っており、**新規アカウントでも初速が出る余地がある**。

> 出典: [Instagramアルゴリズム2026(comnico)](https://www.comnico.jp/we-love-social/ig-algorithm) / [リールアルゴリズム解説](https://tatap.jp/knowledge/instagram-reel-185/) / [カルーセル攻略](https://www.neworder.co.jp/2026/04/19/instagram_carousel_8ro10/)

### 3-2. 競合構造から読み取れる4つの事実

1. **「マンガで体験談」は完全に飽和。**
   トップ層は作画力＋10年級の蓄積＋書籍化実績を持つ。後発が同じ形式で追い抜くのはほぼ不可能。**絵で戦わない設計が必須。**

2. **公式・大手メディアが意外と弱い（LITALICO発達ナビで約2万）。**
   これは重要なシグナル。**このジャンルは「正しい情報」より「個人の生々しさ」が勝つ**ことを意味する。個人参入の余地は大きい。

3. **勝っているのは"極端に狭い属性特化"。**
   「発達特性のある夫と暮らす妻専門」（ちくわ氏）のように、**属性を1つに絞ったアカウントが少ないフォロワー数でも明確なポジションを取っている**。汎用「発達障害育児」で始めるのが一番負ける。

4. **上位層は"重度・知的障害あり"に偏っている。**
   20万人アカウント、書籍化事例はいずれも診断が明確なケース。
   → **逆に「グレーゾーン／診断がつかない／軽度」の層は、母数が最大なのに発信者が薄い。**

### 3-3. 空いているポジション（＝狙うべき場所）

| 空白地帯 | なぜ空いているか | 需要の強さ |
|---|---|---|
| **A. 学齢期〜思春期（小3以降・就学/進路/不登校/二次障害）** | 既存の人気アカは未就学〜低学年の"かわいい時期"が中心。学齢期は絵になりにくく、書きづらい | ★★★ 最強。親の切迫度が最大 |
| **B. 診断前・グレーゾーンの実務** | 「診断ついてないのに語る資格ない」と発信者が自主規制しがち | ★★★ 母数最大（8.8%の中核） |
| **C. 父親／夫婦の温度差** | 発信者がほぼ母親一択。「夫が理解しない」問題は語られるが**当事者視点の解決策**がない | ★★☆ 競合ほぼ皆無 |
| **D. 制度・お金・手続きの実務**（受給者証、通級、就学相談、特別児童扶養手当、放デイの選び方） | 情報が行政サイトに散在し、読み解きが面倒。誰も"翻訳"していない | ★★★ 保存・DM共有が爆発的に発生する型 |

**推奨: B/D を軸に、Aへ伸ばす。**「診断がつく前から使える、具体的な動き方と制度の翻訳」。マンガ不要、テキストと図解で成立し、**保存・DM共有というInstagram 2026の最重要指標に直撃する**。

## 4. 推奨戦略

### 4-1. 役割分担

```
Threads（毎日・主戦場）          Instagram（週2-3・資産）
─────────────────────           ─────────────────────
・短文で"あるある"と問い       ・Threadsで反応が良かった
・返信で1対1の会話を伸ばす  →    ネタだけをカルーセル/リール化
・ネタとニーズの発掘装置        ・保存される「使える表」を作る
・ゼロ円・顔出しゼロ            ・プロフィール導線で収益化
```

Threadsは**リサーチ装置**として使う。反応の取れた投稿だけをInstagramに転用すれば、制作コストの無駄打ちが消える。

### 4-2. コンテンツ型（そのまま使える7型）

| 型 | 例 | 狙う指標 |
|---|---|---|
| 制度翻訳 | 「受給者証、申請から利用開始まで実際の6ステップと所要日数」 | 保存 |
| 言い換え表 | 「"早くして"を"あと3つ"に変えるだけで動く理由」 | 保存・DM共有 |
| 面談テンプレ | 「担任面談で、こう言うと支援が動く／こう言うと止まる」 | 保存 |
| 失敗共有 | 「私が最初の1年でやらかした3つ」 | 返信（Threads向き） |
| 問いかけ | 「診断名を子ども本人にいつ伝えました？」 | **返信＝Threads最重要指標** |
| 数字・事実 | 「小中学生の8.8%。11人に1人。うちだけじゃない」 | シェア |
| 夫婦・家族 | 「"甘やかしすぎ"と言う夫に効いた説明の順番」 | DM共有（配偶者に送られる） |

Threadsは**投稿の末尾に必ず問いを置く**。返信数が初動シグナルを決めるため、これは技術というより必須要件。

### 4-3. 90日ロードマップ

| 期間 | やること | 目標 |
|---|---|---|
| Day 1-30 | Threads1日2投稿＋**受け取った返信に全部返す**。Instagramはプロフィールと固定3投稿だけ用意 | Threads 1,000フォロワー／ネタ帳50本 |
| Day 31-60 | 反応上位10本をInstagramカルーセル（8〜10枚）に変換。リールは15〜60秒で冒頭3秒に「11人に1人」等の数字フック | IG 保存率が平均を超える型を2つ特定 |
| Day 61-90 | 勝ちパターンを週3で量産。DMで届く相談を分類 → 商品/サービスの仮説を立てる | IG 3,000〜5,000／収益導線1本 |

### 4-4. 収益化の順序

**フォロワー数より「相談の深さ」で稼ぐジャンル**。以下の順で。

1. **アフィリエイト／書籍・教材紹介**（早期から可。療育教材、学習支援、書籍）
2. **事業者タイアップ**（放デイ・児発・オンライン療育・学習塾。市場が急拡大しており広告予算がある。フォロワー1万未満でも地域事業者となら成立）
3. **有償コンテンツ**（就学準備チェックリスト、面談テンプレ集 → note/Brain等）
4. **個別相談・コミュニティ**（月額。ただし**資格の有無を明示すること**が必須）
5. **書籍化・講演**（20万フォロワー事例、KADOKAWA書籍化事例のように実在ルート。ただし数年スパン）

> 注意: 「ママ起業コンサル」的な高額情報商材への横滑りは、このジャンルでは**信頼を一瞬で失う**。弱っている親を相手にしている自覚が要る。

## 5. リスクと守るべき一線

| リスク | 対策 |
|---|---|
| **シェアレンティング**（子の顔・名前・学校・診断名の公開）。一度出たら回収不能。制服や行事から居住地・学校が特定される | **顔出ししない／名前は仮名／学校名・地名・行事写真を出さない。**Threads主体ならそもそも写真不要。将来子ども本人が読む前提で書く |
| **診断名の公表は子ども本人の情報**であり、親が代わりに公開する権利は本来ない | 診断名を看板にせず「困りごと」ベースで語る。子が読む年齢になったら削除できる設計に |
| **医療・断定的アドバイス**（YMYL領域） | 「うちの場合」に徹する。治る・改善する等の断定は避け、専門機関（発達障害者支援センター等は無料・診断不要で相談可）への導線を必ず添える |
| **「発達障害インフルエンサー」批判** — このジャンルは発信者への風当たりが実在する | 他家庭・支援者・学校を断罪しない。主語を自分に固定する |
| 燃え尽き | Threadsは返信対応が命だが無制限にやると壊れる。返信対応の時間を先に決める |

> 出典: [シェアレンティングのリスク(講談社コクリコ)](https://cocreco.kodansha.co.jp/cocreco/general/health/xI2Q4) / [データのじかん](https://data.wingarc.com/what-is-sharenting-92301) / [発達障害情報ポータル 相談窓口](https://hattatsu.go.jp/supporter/welfare/faq/welfare-faq01/)

## 6. まとめ

- **需要**: ★★★ 母数（8.8%＝11人に1人）・成長率（通所支援45.7万人、10年で数倍）・切迫度すべて高い
- **Threadsの地合い**: ★★★ 日本で利用時間2.3倍、返信重視アルゴリズム、テキストのみ＝顔出し不要。**今が入り時**
- **Instagramの競合**: ★☆☆（マンガ体験談として入る場合）／ ★★★（制度・実務・学齢期として入る場合）
- **決め手**: マンガで戦わない。**「グレーゾーン期の動き方」＋「制度の翻訳」＋「学齢期」**でポジションを取る

やるなら **Threadsを毎日、Instagramを週2〜3**。Threadsでネタとニーズを掘り、勝った切り口だけInstagramで保存資産に変える。
