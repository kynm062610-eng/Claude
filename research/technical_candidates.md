# テクニカル手法 候補リサーチ(2026-09-24)

YouTube・note・個人ブログで人気のテクニカル手法を集め、**手元の1分足OHLCから機械的に検証できる形**に落とした候補リスト。
シグナルの時間足は5分足・15分足・1時間足を主に使う(1分足は約定評価用。2026-09-24 改訂)。
まだ1つも検証していない。検証前に research_ledger.md の既存9候補と重複していないか確認すること。

> 注: このクラウド環境からは note.com・個人ブログの本文を開けない(ネットワーク制限)ため、ルールは検索結果の要約から再構成している。
> 各手法の「元ネタ」と完全一致ではなく、**検証用に一意に定義し直したもの**として扱う。

## 0. 先に押さえておく前提

1. **学術的な先行結果は厳しい。** Neely & Weller (2003) は、為替の日中テクニカルルールは
   現実的な取引コストを入れ、流動性の高い時間帯に限定すると利益機会の証拠がないと報告。
   テクニカルルールの利益は知られるほど減衰する、という結果も複数ある。
2. **人気手法の多くは裁量を含む。** 「ダウ理論」「水平線」「ネックライン」「環境認識」は人によって定義が違う。
   機械化するときの定義の選び方そのものが自由度になり、試行数(DSRのN)を膨らませる。
   → **定義は検証前に1つに固定し、ここに書いたとおりに実装する。** 結果を見てから定義を変えたら、それは新しい試行。
3. **シグナルは5分足・15分足、約定は1分足。** 1分足スキャルは1トレードの値幅が小さく、スプレッド
   (USDJPYで0.2〜0.3pips程度)が期待値の大半を食うため主軸から外した。5分足・15分足なら1トレードの値幅が数倍になり、コストの比率が下がる。
   約定は **シグナル足(5分/15分)の終値 = その足の最後の1分足の終値** で評価し、コストを控除する
   (ORB の `--entry-mode close` と同じ約束事。台帳の教訓「足の確定後に実際に取れる価格で評価する」)。
   損切り・利確のヒット判定も1分足で行う(同じ5分足の中で損切りと利確の両方に触れた場合の曖昧さを消せる)。
   時間足を長くするとトレード数は減るので、必要トレード数を満たすかを先に見積もる。
4. **台帳との照合結果(2026-09-24、台帳を読んで確認):**
   - 「ロンドンブレイクアウト」「東京ボックスブレイク」= ORB(#8・#9 却下)と同じ構造 → **除外**
   - T5 ボラティリティ・ブレイクアウト = ORB・暗号資産 #2 ブレイクアウト(却下)と同じ系統 → **除外**
   - T3 BBスクイーズ→ブレイク ≒ 台帳の検証待ち「TTMスクイーズ」(Carter)。**同じ候補として扱い、試行は1回分**
   - 台帳の検証待ち「東京仲値アノマリー」「ロンドン・NYオーバーラップ逆張り」は構造系の候補として別枠で残す
5. **試行数:** 台帳の累積は9。以下の候補を1つ検証するたびにN=10, 11, … と増やす。
   同じ手法のパラメータ違いも1試行ずつ数える。

## 1. 候補一覧(機械化した定義)

時刻はすべてUTCで定義(データのタイムゾーンは fx_data.py 側で要確認)。
上位足は1分足からリサンプリングし、**確定した足だけ**を使う(先読み防止)。

### T1. パーフェクトオーダー + 押し目(ぶせな式・グランビルの法則の機械化)
- **出典の系統:** 「移動平均線がパーフェクトオーダー」+「ネックラインが引ける」でエントリーする順張り(ぶせな氏ブログ)、グランビルの押し目買い。
- **定義:**
  - 環境: 1時間足 SMA20 > SMA75 > SMA200 かつ3本とも前の足より上向き → 買いのみ(売りは逆)。
  - トリガー: 5分足の安値がSMA20(5分足)に触れた後、5分足終値がSMA20の上で確定。
  - 約定: トリガー確定の次の1分足の終値。
  - 損切り: 直近12本(5分足=1時間分)の最安値の1pip下。利確: 損切り幅×1.5。時間切れ: 24時間。
- **想定トレード数:** 年数百回/ペア → 必要トレード数は満たしやすい。

### T2. ダウ理論のマルチタイムフレーム押し目(note系で最多の型)
- **出典の系統:** 「上位足で環境認識 → 下位足の転換で入る(上位足の押し目買い)」(ずん氏ほか多数)。
- **定義:**
  - スイング高値・安値: 左右3本より高い(安い)足をフラクタルとして確定(右3本の確定後に初めて使える)。
  - 環境: 1時間足で直近2つのスイング高値・スイング安値がともに切り上がり → 上昇トレンド。
  - トリガー: 5分足が直近の5分足スイング安値を割らずに、直近の5分足スイング高値を終値で上抜け(下位足の下降→上昇転換)。
  - 損切り: 直近の5分足スイング安値の1pip下。利確: 1時間足の直近スイング高値。ただし損切り幅の1倍未満なら見送り。
  - 下位足の「下降」: 5分足の直近2つのスイング高値が切り下がっていること。上抜けは「前の足の終値が水準以下 → 今の足の終値が上」の初回のみ。
  - 時間切れ: 24時間(週末をまたぐ場合は金曜最後の1分足の終値)。建玉は同時に1つまで。
  - 損切りを窓で飛び越えた場合は始値で約定、同じ1分足で損切りと利確の両方に触れたら損切り優先。
- **注意:** フラクタル幅(3本)と時間足の組み合わせが最大の自由度。**3本・1時間/5分で固定**し、変えない。
- **状態:** **却下(2026-09-24、台帳 #10 USDJPY / #11 EURUSD)。** PF 0.893 / 0.910、コストゼロでも赤字。詳細は research_ledger.md。

### T3. ボリンジャーバンド スクイーズ→エクスパンションのブレイク(15分足、1時間足フィルター)
- **出典の系統:** 「スクイーズからエクスパンションへの移行を狙う」のがBBの王道(OANDA ほか)。
  「スクイーズ局面は値幅が狭いので1分足ではなく5分足以上で」「上位足の方向に絞ってヘッドフェイクを避ける」という解説が多い。
- **定義(15分足):**
  - スクイーズ: BB(20, 2σ) のバンド幅(上限−下限)/ミドルが、直近100本の中で下位20%以内。
  - エントリー: スクイーズ中(または直前)に終値が+2σを上抜け、かつ1時間足の終値がSMA20より上 → 買い(売りは対称)。
  - 決済: 終値がミドルライン(SMA20)を割ったら手仕舞い。損切りはエントリー時のミドルライン。時間切れ: 48本(12時間)。
- **旧T3(1分足BB逆張り)は廃止。** 1分足スキャルはコストで負ける事前確率が高いため。

### T9. 一目均衡表 三役好転・三役逆転(1時間足)
- **出典の系統:** 日本で最も知名度が高いテクニカルの一つ。**公開されている検証結果が割れている:**
  - 「1時間足では期待値が常にプラスで、三役好転がベスト。15分足と4時間足ではおおむねマイナス」(FXを統計する)
  - 「全通貨ペアで三役好転/逆転は全く機能せず、むしろ逆シグナル」(戦略的な投資家)
  - 前者は複数の時間足を試して1時間足を選んだ結果なので、選択バイアスを含む。**1時間足に固定して、公開された主張を手元の2015–2026データで追試する**、という位置づけ。
- **定義(1時間足、パラメータは標準の9/26/52):**
  - 三役好転: ①転換線 > 基準線、②遅行スパン(26本前にずらした終値)> 26本前の終値、③終値 > 雲の上限。3条件が初めてそろった足の確定でシグナル。
  - 買い: 三役好転の確定 → 次の1分足の終値で買い。売りは三役逆転で対称。
  - 決済: 転換線が基準線を下回ったら手仕舞い。損切りは基準線の1pip下(エントリー時点の値で固定)。
- **想定トレード数:** 1時間足で三役がそろう回数は少ない(年数十回/ペア程度?)。**必要トレード数に届くかを最初に確認し、届かなければ検証しない。**

### T10. MACD + 200EMA(15分足。YouTubeの定番)
- **出典の系統:** 「200EMAより上で、MACDがゼロラインより下でゴールデンクロスしたら買い、リスクリワード1:1.5」という動画が数百万回再生されている。
  主張は勝率86%などだが、**独立した追試では勝率21%**、S&P500先物の27年検証では32%という報告がある。
- **定義(15分足):**
  - 買い: 終値 > EMA200、かつ MACD(12,26,9) のMACD線がシグナル線を下から上に抜け、その時点でMACD線 < 0。
  - 損切り: 直近10本(2.5時間)の最安値の1pip下。利確: 損切り幅×1.5。売りは対称。
- **位置づけ:** 優位性の事前確率は低い。検証するなら「有名な主張の追試」として。優先度は T9 より下。

### T4. RCI 3本(9/26/52)の順張り押し目
- **出典の系統:** 「RCI3本」手法(短期・中期・長期のRCIの並びで判断。-80%以下でのゴールデンクロスは強いシグナル)。
- **定義(15分足):**
  - 環境: RCI52 > 0 かつ RCI26 > 0 → 買いのみ。
  - トリガー: RCI9 が -80 を下から上に抜けた足の確定。
  - 決済: RCI9 が +80 を上から下に抜けた時点、または損切り=ATR(14)×1.5。

### ~~T5. ボラティリティ・ブレイクアウト(ラリー・ウィリアムズ)~~ → 除外(ORB系で却下済み)
- **出典の系統:** 『ラリー・ウィリアムズの短期売買法』の「ボラティリティ・ブレイクアウト」。暗号資産ボットでも定番。
- **定義:**
  - 日の区切り: NY 17:00(FXの日足の標準的な区切り)。
  - 買い: 当日始値 + 0.5 × 前日レンジ(高値−安値)を1分足終値で上抜け。売りは対称。1日各方向1回まで。
  - 決済: 当日の区切り(翌NY17:00の直前の1分足終値)で手仕舞い。損切り: 前日レンジ×0.5。
- **想定トレード数:** 約2,800営業日 × 発生率 → 1,000回超/ペア。
- **注意:** ORB(orb_research.py)と構造が近い。台帳と照合。

### T6. 日中モメンタム(学術寄り)
- **出典の系統:** Elaut, Frömmel & Lampaert (2018, *Journal of Financial Markets*)。RUB/USDで「最初の30分のリターンが最後の30分のリターンを正に予測する」ことを確認。
  原因は情報トレーダーではなく、**流動性供給者がポジションを持ち越したくないこと**(=構造的な理由がある)。
- **FXへの置き換え(定義):**
  - 1日の区切り: NY 17:00。
  - シグナル: 最初の区間(東京時間 00:00–00:30 UTC)の方向。代替案は1つだけ事前登録: ロンドン 07:00–07:30 UTC。
  - 取引: 最終区間(NY 20:30–21:00 UTC 相当 = 日の区切り前の30分)にシグナル方向で建て、区切り直前の1分足終値で決済。
- **注意:** 元論文は取引所で取引されるRUB/USDで、24時間OTCのUSDJPY/EURUSDでそのまま成立する保証はない。
  1取引あたりの値幅が小さいのでスプレッドの影響が大きい。

### T7(優先度低). チャートパターン(ダブルトップ/三尊のネックライン抜け)
- YouTubeで非常に人気だが、ジグザグの閾値・肩の高さの許容差・ネックラインの定義など自由度が多すぎる。
  **機械化した時点で「その定義の手法」になり、元の裁量手法の検証にはならない。** 後回しを推奨。

### T8(優先度低). 移動平均線ゴールデンクロス単体
- ネット上の検証でも勝率4割程度・大きくばらつくという報告が多い。単体の検証価値は低い。T1にフィルターとして吸収済み。

## 2. 推奨する検証順

| 順 | 候補 | 理由 |
|---|---|---|
| ~~1~~ | ~~T2 ダウ理論MTF押し目~~ **却下** | note・YouTubeで最多の型。機械化できれば「ネットの主流手法に優位性があるか」に答えが出る |
| 2 | **T1 パーフェクトオーダー押し目** | 定義の自由度が小さく、トレード数も十分 |
| 3 | **T9 一目均衡表 三役好転(1時間足)** | 公開された検証結果が「1時間足でプラス」「全く機能しない」に割れている。1時間足に固定した追試で白黒がつく。ただしトレード数が足りるかを先に確認 |
| 4 | T3 BBスクイーズ→ブレイク(15分足) | 15分足ならコスト比率が下がる。T1/T2 が全滅なら順張りブレイク系として試す価値あり |
| 保留 | T6 日中モメンタム | 構造的な理由付き。テクニカル枠の結果を見てから |
| 除外 | T5 | ORB(#8・#9)・暗号資産 #2 と同系統で却下済み |
| 保留 | T4, T10 | 優位性の事前確率が低い(T10 は独立した追試で勝率21%の報告あり) |

3つ検証すると N=12 になり、DSRの期待最大シャープ(帰無仮説下)が上がる分、有意のハードルも上がる。
**上から順に1つずつ検証して台帳に記録**し、候補を増やしすぎない。

## 3. 各候補の検証チェックリスト(台帳の判定基準)

- [ ] 約定 = シグナル足(5分/15分/1時間)の終値(=最後の1分足の終値)。コスト控除あり
- [ ] 損切り・利確のヒットは1分足で判定
